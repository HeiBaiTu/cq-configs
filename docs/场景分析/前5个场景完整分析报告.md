## 🏗️ 场景配置结构说明

### 基本配置字段
| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| sceneid | 数字 | 场景唯一标识符 | 0, 1, 2, 3, 4, 5 |
| sceneType | 数字 | 场景类型分类 | 0 (普通场景) |
| scencename | 字符串引用 | 场景名称语言包引用 | Lang.Scenes.s00001 |
| mapfilename | 字符串 | 地图文件名 | "bqmap", "testmap" |
| defaultX/Y | 数字 | 玩家进入默认坐标 | (235, 131) |

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| entityid | 数字 | 怪物实体ID | 1, 112, 127 |
| entityType | 数字 | 实体类型 | 1 (怪物) |
| monsterType | 数字 | 怪物类型 | 1 (普通), 7 (守卫) |
| name | 字符串 | 怪物名称 | "鸡", "卫士" |
| level | 数字 | 怪物等级 | 5, 999 |
| circle | 数字 | 转生等级 | 0, 9, 18 |
