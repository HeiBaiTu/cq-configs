# 场景配置结构说明

## 概述
本文档详细说明了游戏场景配置的结构和各个字段的含义。

## 场景配置基本结构

```lua
[场景ID] = {
    sceneid = 场景ID,
    sceneType = 场景类型,
    scencename = 场景名称引用,
    mapfilename = 地图文件名,
    defaultX = 默认X坐标,
    defaultY = 默认Y坐标,
    area = {区域配置},
    refresh = {怪物刷新配置},
    npc = {NPC配置},
    teleport = {传送门配置},
    hook = {挂机点配置},
    iscall = 是否可召唤,
}
```

## 字段详细说明

### 1. 基本信息字段

#### sceneid
- **类型**: 数字
- **说明**: 场景的唯一标识符
- **示例**: 0, 1, 2, 3, 4, 5

#### sceneType
- **类型**: 数字
- **说明**: 场景类型分类
- **示例**: 0 (普通场景)

#### scencename
- **类型**: 字符串引用
- **说明**: 场景名称的语言包引用
- **示例**: Lang.Scenes.s00001

#### mapfilename
- **类型**: 字符串
- **说明**: 地图文件名
- **示例**: "bqmap", "testmap", "mzmap1"

#### defaultX / defaultY
- **类型**: 数字
- **说明**: 玩家进入场景时的默认坐标
- **示例**: 235, 131

### 2. 区域配置 (area)

```lua
area = {
    {
        name = 区域名称引用,
        notips = 是否显示提示,
        range = {坐标范围},
        center = {中心坐标},
        time = {时间限制},
        attri = {属性配置},
    }
}
```

#### 区域字段说明
- **name**: 区域名称的语言包引用
- **notips**: 是否显示区域提示 (0=显示, 1=不显示)
- **range**: 区域范围坐标数组
- **center**: 区域中心坐标
- **time**: 时间限制配置
- **attri**: 区域属性配置

#### 区域属性类型 (attri)
- **type=1**: 基础属性
- **type=5**: 特殊属性
- **type=6**: 特殊属性
- **type=7**: 特殊属性
- **type=11**: 坐标属性
- **type=14**: 特殊属性
- **type=22**: 特殊属性
- **type=41**: 战争区域属性
- **type=45**: 特殊属性

### 3. 怪物刷新配置 (refresh)

```lua
refresh = {
    {
        count = 刷新数量,
        time = 刷新间隔(秒),
        firstTime = 首次刷新时间(秒),
        x = X坐标,
        y = Y坐标,
        range = 刷新范围,
        entityid = 实体ID,
        progress = 进度值,
    }
}
```

#### 刷新字段说明
- **count**: 每次刷新的怪物数量
- **time**: 刷新间隔时间(秒)
- **firstTime**: 首次刷新时间(秒)
- **x/y**: 刷新坐标
- **range**: 刷新范围(格)
- **entityid**: 怪物实体ID
- **progress**: 进度值(通常为0)

### 4. NPC配置 (npc)

```lua
npc = {
    {id = NPC ID, posx = X坐标, posy = Y坐标}
}
```

#### NPC字段说明
- **id**: NPC的唯一标识符
- **posx**: NPC的X坐标
- **posy**: NPC的Y坐标

### 5. 传送门配置 (teleport)

```lua
teleport = {
    {
        posx = 传送门X坐标,
        posy = 传送门Y坐标,
        dist = 触发距离,
        toSceneid = 目标场景ID,
        toPosx = 目标X坐标,
        toPosy = 目标Y坐标,
        toPosRadius = 目标坐标半径,
        modelid = 模型ID,
        used = 是否启用,
        passid = 通行证ID,
        name = 传送门名称,
        mapHide = 地图是否隐藏,
        opendayLimit = 开放天数限制,
    }
}
```

#### 传送门字段说明
- **posx/posy**: 传送门位置坐标
- **dist**: 触发距离
- **toSceneid**: 目标场景ID
- **toPosx/toPosy**: 目标坐标
- **toPosRadius**: 目标坐标半径
- **modelid**: 传送门模型ID
- **used**: 是否启用 (true/false)
- **passid**: 通行证ID (0=无需通行证)
- **name**: 传送门名称
- **mapHide**: 地图是否隐藏 (true/false)
- **opendayLimit**: 开放天数限制

### 6. 挂机点配置 (hook)

```lua
hook = {
    {x = X坐标, y = Y坐标}
}
```

#### 挂机点字段说明
- **x/y**: 挂机点坐标

### 7. 其他配置

#### iscall
- **类型**: 数字
- **说明**: 是否可召唤 (0=不可召唤, 1=可召唤)

## 配置示例分析

### 示例1: 简单场景配置
```lua
[0] = {
    sceneid = 0,
    sceneType = 0,
    scencename = Lang.Scenes.s00000,
    mapfilename = "testmap",
    defaultX = 100,
    defaultY = 100,
    area = {简单区域配置},
    refresh = {}, -- 无怪物刷新
    npc = {3个NPC},
    teleport = {1个传送门},
    iscall = 0,
}
```

### 示例2: 复杂主城配置
```lua
[1] = {
    sceneid = 1,
    sceneType = 0,
    scencename = Lang.Scenes.s00001,
    mapfilename = "bqmap",
    defaultX = 235,
    defaultY = 131,
    area = {多个区域配置},
    refresh = {大量怪物刷新配置},
    npc = {18个NPC},
    teleport = {20个传送门},
    hook = {13个挂机点},
    iscall = 1,
}
```

## 配置最佳实践

### 1. 场景ID规划
- 从0开始连续编号
- 主城场景使用较小的ID
- 功能场景使用中等ID
- 高级场景使用较大的ID

### 2. 坐标系统
- 使用整数坐标
- 保持坐标的合理性
- 避免坐标冲突

### 3. 怪物刷新配置
- 合理设置刷新时间
- 控制刷新数量
- 设置合适的刷新范围

### 4. 传送门配置
- 设置合理的触发距离
- 配置正确的目标坐标
- 使用合适的模型ID

### 5. 区域属性配置
- 根据场景类型设置属性
- 合理配置安全区域
- 设置战争区域属性

## 注意事项

1. **语言包引用**: 场景名称和区域名称使用语言包引用
2. **坐标系统**: 所有坐标使用(x,y)格式
3. **时间单位**: 时间配置使用秒为单位
4. **ID唯一性**: 确保所有ID的唯一性
5. **配置完整性**: 确保必要字段的完整性
6. **性能考虑**: 合理控制怪物刷新数量和频率
