# 召唤技能互斥机制实现指南

## 概述

本指南详细说明如何实现道士召唤神兽和召唤月灵技能的互斥机制，包括设置面板配置、服务器端逻辑实现、以及召唤物管理机制。

## 技能基本信息

### 召唤神兽
- **技能ID**: 30
- **技能名称**: 召唤神兽
- **学习等级**: 35级
- **召唤物类型**: 神兽 (近战物理攻击)
- **魔法消耗**: 5点
- **冷却时间**: 1.5秒

### 召唤月灵
- **技能ID**: 34
- **技能名称**: 召唤月灵
- **学习等级**: 需要技能书学习
- **召唤物类型**: 月灵 (远程魔法攻击)
- **魔法消耗**: 8点
- **冷却时间**: 1.5秒

## 互斥机制设计

### 核心问题解答

#### 1. 已经召唤神兽后，还能召唤月灵吗？
**答案**: 可以，但会替换掉神兽

**实现逻辑**:
```lua
-- 召唤新召唤物时的处理逻辑
function OnSummonCast(skillId, playerId)
    if skillId == 30 or skillId == 34 then  -- 召唤神兽或召唤月灵
        -- 1. 检查是否已有召唤物
        local existingSummon = GetPlayerSummon(playerId)
        if existingSummon then
            -- 2. 清除现有召唤物
            RemoveSummon(playerId, existingSummon)
            -- 3. 发送提示消息
            SendMessage(playerId, "原有召唤物已消失")
        end
        
        -- 4. 召唤新的召唤物
        CreateSummon(playerId, skillId)
    end
end
```

#### 2. 如何回收原来的神兽？
**答案**: 自动回收机制

**回收方式**:
1. **主动回收**: 玩家手动释放新召唤技能
2. **自动回收**: 召唤物死亡或时间到期
3. **强制回收**: 服务器端检测到互斥时自动回收

### 方案3: 服务器端互斥逻辑实现

#### 3.1 召唤物管理逻辑

```lua
-- 召唤物管理模块
local SummonManager = {}

-- 获取玩家当前召唤物
function SummonManager.GetPlayerSummon(playerId)
    local playerData = GetPlayerData(playerId)
    return playerData.currentSummon
end

-- 设置玩家召唤物
function SummonManager.SetPlayerSummon(playerId, summonData)
    local playerData = GetPlayerData(playerId)
    playerData.currentSummon = summonData
    SavePlayerData(playerId, playerData)
end

-- 清除玩家召唤物
function SummonManager.RemovePlayerSummon(playerId)
    local playerData = GetPlayerData(playerId)
    if playerData.currentSummon then
        -- 在游戏中移除召唤物实体
        RemoveSummonEntity(playerId, playerData.currentSummon.id)
        -- 清除数据
        playerData.currentSummon = nil
        SavePlayerData(playerId, playerData)
        return true
    end
    return false
end

-- 检查召唤技能互斥
function SummonManager.CheckSummonExclusive(skillId, playerId)
    local exclusiveGroups = {
        [1] = {30, 34}  -- 召唤神兽和召唤月灵互斥组
    }
    
    -- 检查是否属于互斥组
    for groupId, skills in pairs(exclusiveGroups) do
        if table.contains(skills, skillId) then
            -- 检查是否有同组的其他召唤物
            local currentSummon = SummonManager.GetPlayerSummon(playerId)
            if currentSummon then
                local currentSkillId = currentSummon.skillId
                if table.contains(skills, currentSkillId) and currentSkillId ~= skillId then
                    -- 发现互斥，需要先清除现有召唤物
                    SummonManager.RemovePlayerSummon(playerId)
                    -- 发送提示消息
                    SendMessage(playerId, "原有召唤物已消失，召唤新的召唤物")
                end
            end
        end
    end
end

-- 召唤新召唤物
function SummonManager.CreateSummon(playerId, skillId)
    -- 检查互斥
    SummonManager.CheckSummonExclusive(skillId, playerId)
    
    -- 获取召唤物配置
    local summonConfig = GetSummonConfig(skillId)
    if not summonConfig then
        SendMessage(playerId, "召唤物配置错误")
        return false
    end
    
    -- 检查魔法值
    local playerMp = GetPlayerMp(playerId)
    if playerMp < summonConfig.mpCost then
        SendMessage(playerId, "魔法值不足")
        return false
    end
    
    -- 消耗魔法值
    ConsumeMp(playerId, summonConfig.mpCost)
    
    -- 创建召唤物实体
    local summonId = CreateSummonEntity(playerId, summonConfig)
    
    -- 保存召唤物数据
    local summonData = {
        id = summonId,
        skillId = skillId,
        type = summonConfig.type,
        createTime = GetCurrentTime(),
        duration = summonConfig.duration
    }
    SummonManager.SetPlayerSummon(playerId, summonData)
    
    -- 发送成功消息
    SendMessage(playerId, "召唤成功！")
    return true
end

return SummonManager
```

function OnSummonDeath(summonId, playerId)

    SummonManager.RemovePlayerSummon(playerId)
    SendMessage(playerId, "召唤物已死亡")
end

-- 召唤物时间到期处理
function OnSummonExpire(summonId, playerId)
    local SummonManager = require("SummonManager")

    SendMessage(playerId, "召唤物时间到期")
end

## 游戏逻辑详解

### 召唤流程

#### 1. 正常召唤流程
```
玩家释放召唤技能 → 检查互斥 → 清除现有召唤物 → 创建新召唤物 → 保存数据
```

#### 2. 互斥处理流程
```
玩家释放召唤技能 → 检查是否有其他召唤物 → 清除现有召唤物 → 发送提示 → 创建新召唤物
```

### 召唤物回收机制

#### 1. 主动回收
- **触发条件**: 玩家释放新的召唤技能
- **处理方式**: 立即清除现有召唤物
- **提示消息**: "原有召唤物已消失"

#### 2. 自动回收
- **触发条件**: 召唤物死亡或时间到期
- **处理方式**: 自动清除召唤物数据
- **提示消息**: "召唤物已死亡" 或 "召唤物时间到期"

#### 3. 强制回收
- **触发条件**: 服务器检测到数据异常
- **处理方式**: 强制清除所有召唤物
- **提示消息**: "召唤物数据异常，已清除"
