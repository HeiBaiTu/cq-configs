- **技能ID**: 31
- **技能名称**: 气功波

- **技能类型**: 主动技能 (skillType: 2)
- **技能分类**: 基础技能 (skillClass: 1)
- **学习等级**: 38级自动学习
- **状态**: 正常使用

## 技能配置详情
```lua
[31] = {
    id = 31,
    name = "气功波",
    vocation = 3,
    skillType = 2,           -- 主动技能
    skillClass = 1,          -- 基础技能类
    commonCd = 750,          -- 公共冷却时间750ms
    isSwitch = false,        -- 非切换技能
    specialBuffCond = 0,     -- 无特殊BUFF条件
    priority = 0,            -- 优先级0
    isAutoLearn = true,      -- 自动学习
    autoLearnSkillLvl = 38,  -- 38级自动学习
    direction = 0,           -- 无方向要求
    action = 2,              -- 动作类型2
}
```

## 技能说明
气功波是道士的控制技能，38级时自动学习。该技能可以推开周围的敌人，为道士创造安全距离，是道士重要的保命技能。

## 技能特点
- **推开效果**: 推开周围的所有敌人
- **防御技能**: 主要用于保护自己
- **范围技能**: 影响周围所有敌人
- **无方向要求**: 不需要指定方向
- **即时生效**: 立即推开敌人

## 使用场景
- **被近身时**: 推开靠近的敌人
- **PK战斗**: 与战士保持距离
- **刷怪安全**: 在怪物包围时使用
- **团队配合**: 为队友创造空间

## 使用技巧
- 在被敌人近身时立即使用
- 可以配合其他技能形成连击
- 注意冷却时间，合理使用
- 在PK中用于保持距离
- 掌握最佳使用时机

## 学习建议
- 38级时自动学习
- 建议熟练掌握使用时机
- 是道士重要的保命技能
- 注意技能释放的时机和位置
