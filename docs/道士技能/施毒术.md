# 施毒术

## 技能基本信息
- **技能ID**: 23
- **技能名称**: 施毒术
- **职业**: 道士 (vocation: 3)
- **技能类型**: 主动技能 (skillType: 2)
- **技能分类**: 基础技能 (skillClass: 1)
- **学习等级**: 13级自动学习
- **状态**: 正常使用

## 技能配置详情
```lua
[23] = {
    id = 23,
    name = "施毒术",
    vocation = 3,
    skillType = 2,           -- 主动技能
    skillClass = 1,          -- 基础技能类
    commonCd = 750,          -- 公共冷却时间750ms

    isSwitch = false,        -- 非切换技能
    specialBuffCond = 0,     -- 无特殊BUFF条件

    isAutoLearn = true,      -- 自动学习
    autoLearnSkillLvl = 13,  -- 13级自动学习

}
```

## 技能说明
施毒术是道士的基础攻击技能，13级时自动学习。该技能可以对敌人施放毒素，造成持续伤害，是道士重要的输出技能。

## 技能特点
- **持续伤害**: 对敌人造成持续伤害
- **毒素效果**: 施放毒素状态
- **单体攻击**: 对单个目标施放
- **无方向要求**: 不需要指定方向

## 使用场景
- **PK战斗**: 对敌人造成持续伤害
- **打BOSS**: 对BOSS造成持续伤害
- **消耗战**: 在长时间战斗中发挥效果
- **团队配合**: 为队友提供输出支持

## 使用技巧
- 在战斗开始时就施放毒素
- 可以配合其他技能形成连击
- 注意毒素的持续时间
- 在PK中用于消耗敌人血量

## 学习建议
- 13级时自动学习
- 建议在战斗开始时就使用
- 是道士重要的输出技能
