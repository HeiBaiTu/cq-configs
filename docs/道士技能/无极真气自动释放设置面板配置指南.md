# 无极真气自动释放设置面板配置指南

## 概述

本指南详细说明如何将无极真气技能的自动释放功能添加到游戏设置面板中，让道士玩家可以在设置中开启无极真气的自动释放。

## 技能信息

### 无极真气基本信息
- **技能ID**: 32
- **技能名称**: 无极真气
- **职业**: 道士
- **技能类型**: 主动技能
- **自动释放**: 效果消失后自动施放

## 设置面板结构分析

### 当前设置面板分类
设置面板按职业分类管理技能自动释放：

| 职业 | 配置项 | 说明 |
|------|--------|------|
| 战士 | skills1 | 战士技能自动释放配置 |
| 法师 | skills2 | 法师技能自动释放配置 |
| 道士 | skills3 | 道士技能自动释放配置 |

### 现有道士技能配置
```lua
skills3 = {
    {pos=1, skillId=28, tips="效果消失后，自动施放神圣战甲术", value=1}
}
```

## 配置步骤

### 1. 修改后端配置

**文件位置**: `data/config/setting/basicsSetting.config`

**修改内容**:
```lua
--S-设置.xlsx 基础设置
BasicsSettingmConfig={
    [1] = {tips="显示全部人物名字",value=1},
    [2] = {tips="显示全部怪物名字",value=1},
    [3] = {tips="显示他人展示的称号(自己称号在角色-称号中设置显示)",value=1},
    [4] = {tips="持续显示当前网络延迟",value=0},
    [5] = {tips="获得本职业属性更好的装备时，自动推荐并穿戴",value=1},
    [6] = {tips="废弃1",value=0},
    [7] = {tips="勾选后，开启任务箭头提醒和自动做任务功能",value=0},
    [8] = {tips="勾选后，受到玩家攻击将出现反击列表，点击可自动反击",value=1},
    -- 战士技能自动释放
    skills1 = {{pos=1,skillId=6,tips="自动使用烈火剑法技能",value=1},{pos=2,skillId=8,tips="自动使用逐日剑法技能",value=1}},
    -- 法师技能自动释放
    skills2 = {{pos=1,skillId=17,tips="自动开启魔法盾",value=1}},
    -- 道士技能自动释放 (添加无极真气)
    skills3 = {
        {pos=1,skillId=28,tips="效果消失后，自动施放神圣战甲术",value=1},
        {pos=2,skillId=32,tips="效果消失后，自动施放无极真气",value=1}
    },
    previlege = {pos=4,name="智能回收",tips="装备包裹达100格自动触发一键回收。白卡会员可获得特权卡"},
    showPet = {tips="勾选后可显示全部他人宠物",value=1},
}
```

## 配置参数说明

### 参数详解

| 参数名 | 类型 | 说明 | 示例值 |
|--------|------|------|--------|
| pos | 数字 | 位置编号，用于排序显示 | 1, 2, 3... |
| skillId | 数字 | 技能ID，对应技能配置中的ID | 32 (无极真气) |
| tips | 字符串 | 设置面板中显示的提示文字 | "效果消失后，自动施放无极真气" |
| value | 数字 | 默认值，1表示开启，0表示关闭 | 1 (默认开启) |

### 技能ID对照表

| 技能名称 | 技能ID | 职业 | 自动释放类型 |
|----------|--------|------|-------------|
| 烈火剑法 | 6 | 战士 | 自动使用 |
| 逐日剑法 | 8 | 战士 | 自动使用 |
| 魔法盾 | 17 | 法师 | 自动开启 |
| 神圣战甲术 | 28 | 道士 | 效果消失后自动施放 |
| 无极真气 | 32 | 道士 | 效果消失后自动施放 |

## 显示效果

### 设置面板显示
在游戏设置面板中，道士职业会看到以下选项：

```
技能自动释放设置：
☑ 效果消失后，自动施放神圣战甲术
☑ 效果消失后，自动施放无极真气
```

### 功能说明
- **神圣战甲术**: 防御BUFF消失后自动重新施放
- **无极真气**: 攻击BUFF消失后自动重新施放

## 注意事项

### 1. 配置一致性
- 前后端配置必须保持一致
- 技能ID必须正确对应
- 参数格式必须符合要求

### 2. 职业限制
- 只有道士职业会看到无极真气设置
- 其他职业不会显示此选项

### 3. 自动释放逻辑
- 需要在服务器端实现自动释放逻辑
- 确保技能冷却时间正确处理
- 验证BUFF状态检测机制

### 4. 兼容性考虑
- 确保与现有技能自动释放功能兼容
- 不影响其他职业的技能设置
- 保持设置面板的稳定性

## 故障排除

### 常见问题

#### 1. 设置选项不显示
**原因**: 前端配置未正确更新
**解决**: 检查JSON语法，确保配置正确

#### 2. 自动释放不生效
**原因**: 服务器端逻辑未实现
**解决**: 检查服务器端自动释放逻辑

#### 3. 配置冲突
**原因**: 前后端配置不一致
**解决**: 对比两个配置文件，确保一致性

### 调试方法
1. 检查服务器日志
2. 验证配置文件语法
3. 测试技能ID是否正确
4. 确认职业限制逻辑

## 扩展功能

### 未来可能的扩展
1. **技能优先级设置**: 多个BUFF同时消失时的释放顺序
2. **条件触发**: 根据血量、蓝量等条件触发自动释放
3. **冷却时间显示**: 在设置面板显示技能冷却时间
4. **批量设置**: 一键开启/关闭所有技能自动释放

## 总结

通过本指南的配置，可以成功将无极真气的自动释放功能添加到设置面板中。配置完成后，道士玩家就可以在设置中方便地开启无极真气的自动释放功能，提升游戏体验。

### 关键要点
1. **技能ID**: 无极真气技能ID是32
2. **配置位置**: 添加到skills3数组中
3. **参数设置**: pos=2, skillId=32, tips="效果消失后，自动施放无极真气"
