# 召唤神兽

## 技能基本信息
- **技能ID**: 30
- **技能名称**: 召唤神兽
- **职业**: 道士 (vocation: 3)
- **技能类型**: 主动技能 (skillType: 2)
- **技能分类**: 基础技能 (skillClass: 1)
- **学习等级**: 35级自动学习
- **状态**: 正常使用

## 技能配置详情
```lua
[30] = {
    id = 30,
    name = "召唤神兽",
    vocation = 3,
    skillType = 2,           -- 主动技能
    skillClass = 1,          -- 基础技能类
    commonCd = 750,          -- 公共冷却时间750ms
    isSwitch = false,        -- 非切换技能
    specialBuffCond = 0,     -- 无特殊BUFF条件
    priority = 0,            -- 优先级0
    isAutoLearn = true,      -- 自动学习
    autoLearnSkillLvl = 35,  -- 35级自动学习
    direction = 0,           -- 无方向要求
    action = 2,              -- 动作类型2
}
```

## 技能说明
召唤神兽是道士的终极召唤技能，35级时自动学习。该技能可以召唤强大的神兽协助战斗，是道士最重要的辅助技能。

## 技能特点
- **终极召唤**: 召唤强大的神兽协助战斗
- **高战斗力**: 神兽具有强大的战斗力
- **持续存在**: 神兽会持续存在
- **无方向要求**: 不需要指定方向

## 使用场景
- **刷怪升级**: 神兽协助攻击怪物
- **PK战斗**: 增加战斗优势
- **打BOSS**: 神兽协助攻击BOSS
- **团队配合**: 为团队提供强大战斗力

## 使用技巧
- 在战斗开始时就召唤神兽
- 注意神兽的生存和召唤时机
- 可以配合其他技能使用
- 在PK中用于增加战斗优势

## 学习建议
- 35级时自动学习
- 建议在战斗开始时就召唤
- 是道士最重要的辅助技能
