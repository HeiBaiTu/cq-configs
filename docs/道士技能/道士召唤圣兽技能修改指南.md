## 修改方法

### 1. 增加血量
要增加召唤圣兽的血量，需要修改 `Props.json` 文件中对应 propid 的 `nMaxHpAdd` 值：

**示例修改**：
```json
// 修改神兽Lv1血量从600增加到1200
"115": {
  "nMaxHpAdd": 1200,  // 原来是600，现在改为1200
  // ... 其他属性保持不变
}

// 修改神兽Lv2血量从900增加到1800
"116": {
  "nMaxHpAdd": 1800,  // 原来是900，现在改为1800
  // ... 其他属性保持不变
}
```

### 2. 增加防御
要增加召唤圣兽的防御，需要修改 `Props.json` 文件中对应 propid 的防御相关属性：

**物理防御修改**：
```json
"115": {
  "nPhysicalDefenceMinAdd": 50,  // 原来是10，现在改为50
  "nPhysicalDefenceMaxAdd": 100, // 原来是20，现在改为100
  // ... 其他属性保持不变
}
```

**魔法防御修改**：
```json
"115": {
  "nMagicDefenceMinAdd": 50,  // 原来是10，现在改为50
  "nMagicDefenceMaxAdd": 100, // 原来是20，现在改为100
  // ... 其他属性保持不变
}
```

### 3. 修改造型
要修改召唤圣兽的造型，需要修改 `Monster.json` 文件中的 `modelid` 值：

**示例修改**：
```json
// 修改神兽Lv1的造型
"129": {
  "name": "神兽Lv1",
  "modelid": 30151,  // 原来是30150，现在改为30151（使用超级圣兽的造型）
  // ... 其他属性保持不变
}
```

**可用的造型ID**：
- `30150`: 普通神兽造型
- `30151`: 超级圣兽造型
- 其他可用的modelid需要查看游戏资源文件

### 4. 修改技能描述
要修改技能描述中的血量数值，需要修改 `SkillsLevelConf.json` 文件中的 `skillDesc` 和 `skillNextDesc`：

**示例修改**：
```json
"30": {
  "1": {
    "skillDesc": "召唤一只守卫神兽体力1200，攻击力为主人物攻、道术、魔法之和的0.2倍+30点",
    "skillNextDesc": "召唤一只守卫神兽体力1800，攻击力为主人物攻、道术、魔法之和的0.24倍+40点",
    // ... 其他属性保持不变
  }
}
```

## 修改步骤总结

1. **备份原文件**：修改前务必备份所有相关配置文件
2. **修改属性配置**：在 `Props.json` 中修改对应 propid 的血量和防御值
3. **修改外观配置**：在 `Monster.json` 中修改对应 entityid 的 modelid
4. **修改技能描述**：在 `SkillsLevelConf.json` 中更新技能描述文本
5. **测试验证**：启动游戏测试修改效果

## 注意事项

1. **数值平衡**：修改属性时要注意游戏平衡性，避免数值过高影响游戏体验
2. **文件格式**：修改JSON文件时要注意保持正确的格式，避免语法错误
3. **客户端同步**：如果游戏有客户端，可能需要同步修改客户端配置文件
4. **版本兼容**：修改前确认游戏版本，不同版本可能有不同的配置结构
