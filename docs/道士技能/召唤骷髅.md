# 召唤骷髅

## 技能基本信息
- **技能ID**: 25
- **技能名称**: 召唤骷髅
- **职业**: 道士 (vocation: 3)
- **技能类型**: 主动技能 (skillType: 2)
- **技能分类**: 基础技能 (skillClass: 1)
- **学习等级**: 19级（需要技能书）
- **状态**: 已删除/禁用 (isDelete: true)

## 技能配置详情
```lua

    name = "召唤骷髅",
    vocation = 3,

```

## 技能说明
召唤骷髅是道士的召唤技能，原本在19级时可以通过技能书学习。该技能可以召唤骷髅战士协助战斗，是道士重要的辅助技能。

## 技能特点
- **召唤技能**: 召唤骷髅战士协助战斗
- **辅助战斗**: 为道士提供额外的战斗力
- **持续存在**: 骷髅会持续存在一段时间
- **无方向要求**: 不需要指定方向

## 使用场景
- **刷怪升级**: 骷髅协助攻击怪物
- **PK战斗**: 增加战斗优势
- **打BOSS**: 骷髅协助攻击BOSS
- **团队配合**: 为团队提供额外战斗力
