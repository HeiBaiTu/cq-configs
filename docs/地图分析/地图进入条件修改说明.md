# 地图进入条件修改说明

## 概述
本文档详细说明如何修改地图的进入条件，包括等级、转生、消耗等要求。

## 配置流程

地图进入条件通过NPC传送系统实现，配置涉及以下文件：

1. **NPC配置** (`data/config/npc/npc.config`) - NPC基本信息
2. **NPC功能配置** (`data/config/npc/functions.config`) - NPC功能组定义
3. **NPC传送配置** (`data/config/npc/npctrance.config`) - 传送条件和目标
4. **场景配置** (`data/envir/Scenes.config`) - 地图场景属性（可选）

## 修改步骤

### 步骤1：找到对应的NPC

在 `data/config/npc/npc.config` 中找到进入地图的NPC配置。

**示例：雪山陵墓NPC (ID: 206)**
```lua
[206] = {
    id = 206,
    name = "",
    talk = "|C:0xfc21ed&T:雪山陵墓|\n|C:0x1be200&T:[地图说明]|此图怪物密度较低，双防高，攻击超高\n|C:0x1be200&T:[进入条件]|6转\n|C:0x1be200&T:[门票消耗]|C:0xda1e00&T:100YB|",
    modelid = 1146,
    funcGroup = {123},  -- 功能组ID
},
```

**关键字段：**
- `funcGroup`: NPC功能组ID，用于关联传送功能

### 步骤2：查找功能组配置

在 `data/config/npc/functions.config` 中查找对应的功能组配置。

**示例：功能组 123**
```lua
[123] = {
    id = 123,
    funcType = 3,  -- 3表示传送类型
    param1 = {201},  -- 传送配置ID列表
},
```

**关键字段：**
- `funcType = 3`: 表示这是传送功能
- `param1`: 传送配置ID数组，包含所有可传送的目标配置

### 步骤3：修改传送配置（核心步骤）

在 `data/config/npc/npctrance.config` 中找到对应的传送配置ID并修改。

**示例：传送配置 201 (雪山陵墓)**
```lua
[201] = {
    id = 201,
    nSceneId = 264,  -- 目标场景ID
    nX = 54,  -- 传送后X坐标
    nY = 41,  -- 传送后Y坐标
    nLevel = 0,  -- 等级要求（0表示无要求）
    openDay = 0,  -- 开服天数要求（0表示无要求）
    zsLevel = 6,  -- 转生等级要求（6转）
    Consumelist = {{type=4, count=1000}},  -- 消耗列表（1000元宝）
    jionmsg = "|C:0x0066ff&T:%s|自信的进入|C:0xff7700&T:%s|，祝他好运吧！",
},
```

**关键字段说明：**

| 字段 | 说明 | 示例 |
|------|------|------|
| `nSceneId` | 目标场景ID | 264 |
| `nX`, `nY` | 传送后的坐标 | 54, 41 |
| `nLevel` | 角色等级要求 | 0=无要求, 30=30级 |
| `zsLevel` | 转生等级要求 | 0=无要求, 6=6转 |
| `openDay` | 开服天数要求 | 0=无要求, 1=开服1天 |
| `Consumelist` | 消耗物品列表 | 见下方说明 |

**消耗类型 (Consumelist):**
```lua
-- 金币消耗
Consumelist = {{type=2, count=50000}}  -- 5万金币

-- 元宝消耗
Consumelist = {{type=4, count=1000}}  -- 1000元宝

-- 绑金消耗
Consumelist = {{type=2, id=2, count=300000}}  -- 30万绑金

-- 物品消耗
Consumelist = {{type=0, id=298, count=1}}  -- 物品ID 298，数量1

-- 多个消耗
Consumelist = {
    {type=2, count=50000},  -- 5万金币
    {type=0, id=298, count=1},  -- 物品298，数量1
}
```

### 步骤4：更新NPC对话文本（可选）

如果需要更新NPC对话中显示的进入条件，修改 `data/config/npc/npc.config` 中的 `talk` 字段。

**示例：**
```lua
talk = "|C:0xfc21ed&T:雪山陵墓|\n|C:0x1be200&T:[地图说明]|此图怪物密度较低，双防高，攻击超高\n|C:0x1be200&T:[进入条件]|6转\n|C:0x1be200&T:[门票消耗]|C:0xda1e00&T:100YB|"
```

## 完整修改示例

### 示例：修改雪山陵墓进入条件

**需求：** 将进入条件从"6转+1000元宝"改为"5转+500元宝"

**步骤：**

1. **修改传送配置** (`data/config/npc/npctrance.config`)
```lua
[201] = {
    id = 201,
    nSceneId = 264,
    nX = 54,
    nY = 41,
    nLevel = 0,
    openDay = 0,
    zsLevel = 5,  -- 修改：6改为5
    Consumelist = {{type=4, count=500}},  -- 修改：1000改为500
    jionmsg = "|C:0x0066ff&T:%s|自信的进入|C:0xff7700&T:%s|，祝他好运吧！",
},
```

2. **更新NPC对话** (`data/config/npc/npc.config`)
```lua
[206] = {
    id = 206,
    name = "",
    talk = "|C:0xfc21ed&T:雪山陵墓|\n|C:0x1be200&T:[地图说明]|此图怪物密度较低，双防高，攻击超高\n|C:0x1be200&T:[进入条件]|5转\n|C:0x1be200&T:[门票消耗]|C:0xda1e00&T:50YB|",  -- 修改对话文本
    modelid = 1146,
    funcGroup = {123},
},
```

## 常见配置场景

### 场景1：只要求转生等级
```lua
nLevel = 0,
zsLevel = 3,  -- 3转
Consumelist = {},
```

### 场景2：要求等级和转生
```lua
nLevel = 50,  -- 50级
zsLevel = 2,  -- 2转
Consumelist = {},
```

### 场景3：要求转生+消耗
```lua
nLevel = 0,
zsLevel = 6,  -- 6转
Consumelist = {{type=4, count=1000}},  -- 1000元宝
```

### 场景4：要求开服天数+转生
```lua
nLevel = 0,
zsLevel = 3,  -- 3转
openDay = 7,  -- 开服7天
Consumelist = {},
```

### 场景5：多个消耗条件
```lua
nLevel = 0,
zsLevel = 5,
Consumelist = {
    {type=2, count=50000},  -- 5万金币
    {type=0, id=298, count=1},  -- 物品298
},
```

## 注意事项

1. **前后端同步**：如果存在前端JSON配置文件，需要同步修改
2. **配置验证**：修改后需要验证配置语法正确性
3. **测试验证**：修改后建议在测试环境验证功能
4. **对话文本**：NPC的 `talk` 字段只是显示文本，实际限制由传送配置决定
5. **多个传送点**：如果NPC有多个传送选项，`param1` 数组中会有多个传送配置ID

## 相关文件路径

- NPC配置：`data/config/npc/npc.config`
- NPC功能配置：`data/config/npc/functions.config`
- NPC传送配置：`data/config/npc/npctrance.config`
- 场景配置：`data/envir/Scenes.config`
- 前端NPC配置：`split_configs/NpcConfig.json`（如存在）

## 快速查找方法

1. **通过NPC ID查找**：
   - 在 `npc.config` 中找到NPC配置
   - 查看 `funcGroup` 字段
   - 在 `functions.config` 中查找对应功能组
   - 在 `npctrance.config` 中查找传送配置

2. **通过地图ID查找**：
   - 在 `npctrance.config` 中搜索 `nSceneId = 地图ID`
   - 找到对应的传送配置ID
   - 反向查找使用该配置的NPC

## 代码检查逻辑

根据 `data/functions/NpcEvent/NpcTeleport.txt` 中的代码逻辑，进入条件检查顺序：

1. 传送次数限制检查
2. 活动要求检查（如色卡等级）
3. **等级检查** (`nLevel`)
4. **转生检查** (`zsLevel`)
5. 场景传送权限检查
6. **开服天数检查** (`openDay`)
7. **消耗检查** (`Consumelist`)

所有检查通过后才会执行传送。
