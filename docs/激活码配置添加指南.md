# 激活码配置添加指南

## 概述
本文档详细说明如何在游戏中添加新的激活码（CDKey），包括配置结构、添加方法和注意事项。

## 激活码系统架构

### 系统组成
1. **礼包码配置** (`Cdkey.config`): 定义礼包内容和限制
2. **通码配置** (`CommonCdkey.config`): 定义通用激活码
3. **服务配置** (`CdkeyService.config`): 定义平台服务接口
4. **自动激活码服务** (`autoCdkeyService.config`): 后台自动生成服务

## 配置文件详解

### 1. 礼包码配置 (data/config/cdkey/Cdkey.config)

#### 配置结构
```lua
--AA-礼包码CDKey.xlsx 礼包码配置
CDKeyConf={
[ID] = {
    Id = ID,                    -- 礼包ID
    awards = {                  -- 奖励列表
        {type=类型,id=物品ID,count=数量},
        {type=类型,id=物品ID,count=数量},
    },
    limits = 使用次数限制,        -- 每个玩家可使用次数
    mailtitle = "邮件标题",      -- 邮件标题
    mailcontent = "邮件内容",    -- 邮件内容
    switch = 开关状态,           -- 1=开启,0=关闭
},
}
```

#### 奖励类型说明
| type | 类型名称 | 说明 |
|------|----------|------|
| 0 | 物品 | 普通物品奖励 |
| 2 | 金币 | 金币奖励 |
| 7 | 元宝 | 元宝奖励 |

#### 现有礼包示例
```lua
[1] = {
    Id = 1,
    awards = {
        {type=0,id=302,count=1},    -- 物品302 x1
        {type=0,id=421,count=3},    -- 物品421 x3
        {type=7,id=7,count=10},     -- 元宝 x10
        {type=2,id=2,count=10000}   -- 金币 x10000
    },
    limits = 1,                     -- 每个玩家限用1次
    mailtitle = "新手卡礼包",
    mailcontent = "礼包兑换成功，请领取以下道具，祝您游戏愉快！",
    switch = 1,                     -- 开启状态
},
```

## 添加新激活码的方法

### 方法1: 添加新的礼包码

#### 步骤1: 在Cdkey.config中添加新礼包
```lua
[新ID] = {
    Id = 新ID,
    awards = {
        {type=0,id=物品ID,count=数量},
        {type=2,id=2,count=金币数量},
        {type=7,id=7,count=元宝数量},
    },
    limits = 使用次数限制,
    mailtitle = "新礼包标题",
    mailcontent = "新礼包内容描述",
    switch = 1,
},
```

#### 步骤2: 在后台生成对应的激活码
- 激活码会通过后台服务自动生成
- 每个激活码对应一个礼包ID

### 方法2: 添加新的通码

#### 在CommonCdkey.config中添加新通码
```lua
["新激活码"] = {
    cdkey = "新激活码",
    awards = {
        {type=0,id=物品ID,count=数量},
        {type=2,id=2,count=金币数量},
    },
    mailtitle = "系统邮件",
    mailcontent = "感谢您的支持，请查收您的礼包奖励。",
    switch = 1,
},
```

### 方法3: 添加新平台服务

#### 在CdkeyService.config中添加新平台
```lua
["新平台ID"] = {
    PfId = "新平台ID",
    host = "新服务器地址",
    port = "80",
    url = "/Service/CheckGiftCodeLimit.php",
},
```

## 激活码状态码说明

### 返回状态码
| 状态码 | 含义 | 说明 |
|--------|------|------|
| 0 | CODE_SUCCESS | 成功 |
| 1 | CODE_INVALID | 已被使用 |
| 2 | CODE_NOTEXIST | 不存在 |
| 3 | CODE_USED | 已使用过同类型 |
| 4 | CODE_ERR | SQL查询错误 |
| 5 | CODE_TIME | 未到使用时间 |
| 6 | CODE_TIMEEXPIRE | 礼包码过期了 |
| 11 | CODE_HTTP | HTTP接口错误 |
| 12 | CODE_PF | 非本平台礼包码 |
| 13 | CODE_LIMIT | 使用次数超过限制 |

## 添加激活码的完整流程

### 1. 确定激活码类型
- **礼包码**: 通过后台生成，有使用次数限制
- **通码**: 固定激活码，所有玩家都可使用

### 2. 准备奖励物品
- 确定要奖励的物品ID和数量
- 确定金币和元宝奖励数量
- 准备邮件标题和内容

### 3. 修改配置文件
- 根据激活码类型修改对应配置文件
- 确保配置格式正确
- 设置开关状态为1（开启）

### 4. 测试验证
- 在测试环境验证激活码功能
- 检查奖励发放是否正确
- 验证使用次数限制是否生效

### 5. 部署到生产环境
- 备份原配置文件
- 部署新配置
- 监控激活码使用情况

## 注意事项

### 1. 配置格式
- 确保Lua语法正确
- 注意逗号和括号的匹配
- 字符串使用双引号

### 2. 物品ID验证
- 确保奖励的物品ID存在
- 验证物品数量合理
- 检查物品是否可正常获得

### 3. 平台兼容性
- 确保激活码在目标平台可用
- 检查平台服务配置是否正确
- 验证HTTP接口是否正常

### 4. 使用限制
- 合理设置使用次数限制
- 考虑激活码的有效期
- 避免重复发放相同奖励

### 5. 邮件内容
- 邮件标题和内容要清晰明确
- 避免使用特殊字符
- 确保内容符合游戏规范

## 总结

激活码系统支持两种主要类型：
1. **礼包码**: 通过后台服务生成，有使用限制
2. **通码**: 固定激活码，所有玩家可用

添加新激活码需要：
1. 修改对应的配置文件
2. 确保奖励物品存在
3. 设置合理的限制条件
4. 测试验证功能正常

通过以上配置，可以灵活地为游戏添加各种类型的激活码奖励。
