# 怪物攻击速度和攻击范围设置指南

## 概述

怪物的攻击速度和攻击范围是影响战斗体验的重要参数。本指南将详细说明如何正确配置这些参数，以实现平衡的游戏体验。

## 攻击速度设置

### 1. 主要配置参数

#### Monster.config 中的 attackInterval
```lua
attackInterval = 2000,  -- 攻击间隔，单位：毫秒
```

#### Props.config 中的 nAttackSpeed
```lua
nAttackSpeed = 0,  -- 攻击速度调整值，单位：毫秒
```

### 2. 攻击速度计算方式

**最终攻击间隔 = attackInterval + nAttackSpeed**

- `attackInterval`: 基础攻击间隔
- `nAttackSpeed`: 攻击速度调整值（可以为负数来加快攻击）

### 3. 常见攻击速度设置

#### 快速攻击怪物（适合近战、敏捷型）
```lua
-- Monster.config
attackInterval = 500,   -- 0.5秒攻击一次

-- Props.config
nAttackSpeed = -100,    -- 额外减少100ms，最终间隔400ms
```

#### 标准攻击怪物（普通怪物）
```lua
-- Monster.config
attackInterval = 2000,  -- 2秒攻击一次

-- Props.config
nAttackSpeed = 0,       -- 无额外调整
```

#### 慢速攻击怪物（重型、Boss类）
```lua
-- Monster.config
attackInterval = 3000,  -- 3秒攻击一次

-- Props.config
nAttackSpeed = 500,     -- 额外增加500ms，最终间隔3500ms
```

#### 超慢攻击怪物（特殊Boss）
```lua
-- Monster.config
attackInterval = 5000,  -- 5秒攻击一次

-- Props.config
nAttackSpeed = 0,       -- 无额外调整
```

### 4. 攻击速度设置建议

| 怪物类型 | attackInterval | nAttackSpeed | 最终间隔 | 说明 |
|----------|----------------|--------------|----------|------|
| 快速小怪 | 500-800 | -100~0 | 400-800ms | 敏捷型怪物 |
| 普通小怪 | 1500-2000 | 0 | 1500-2000ms | 标准攻击速度 |
| 精英怪物 | 2000-2500 | 0-200 | 2000-2700ms | 稍慢但威力大 |
| 头目怪物 | 2500-3000 | 0-500 | 2500-3500ms | 慢但伤害高 |
| Boss怪物 | 3000-5000 | 0-1000 | 3000-6000ms | 很慢但伤害极高 |
| 特殊Boss | 5000-10000 | 0 | 5000-10000ms | 超慢但一击必杀 |

## 攻击范围设置

### 1. 主要配置参数（在AI.config中）

#### 警戒距离 (watchDistance)
```lua
watchDistance = 4,  -- 发现玩家的距离
```

#### 追击距离 (pursuitDistance)
```lua
pursuitDistance = 18,  -- 追击玩家的最大距离
```

#### 传送距离 (transferDis)
```lua
transferDis = 15,  -- 传送技能的距离
```

### 2. 攻击范围类型

#### 近战攻击范围
```lua
-- AI.config
watchDistance = 2,      -- 近距离发现
pursuitDistance = 3,    -- 短距离追击
transferDis = 0,        -- 无传送技能
```

#### 中距离攻击范围
```lua
-- AI.config
watchDistance = 4,      -- 中等发现距离
pursuitDistance = 8,    -- 中等追击距离
transferDis = 6,        -- 短距离传送
```

#### 远程攻击范围
```lua
-- AI.config
watchDistance = 6,      -- 远距离发现
pursuitDistance = 12,   -- 远距离追击
transferDis = 10,       -- 中距离传送
```

#### 超远程攻击范围

pursuitDistance = 18,   -- 超远追击距离

## 平衡性建议

### 1. 攻击速度平衡原则

- **快速攻击** = 低伤害，高频率
- **慢速攻击** = 高伤害，低频率
- **总DPS应该相近**，避免某些怪物过于强大

### 2. 攻击范围平衡原则

- **近战怪物** = 高伤害，短距离
- **远程怪物** = 中等伤害，长距离
- **Boss怪物** = 高伤害，中等距离，特殊技能

### 3. 配置检查清单

#### 攻击速度检查
- [ ] attackInterval 设置合理（500-10000ms）
- [ ] nAttackSpeed 调整适当（-500~1000ms）
- [ ] 最终攻击间隔符合怪物类型
- [ ] 与伤害值平衡匹配

#### 攻击范围检查
- [ ] watchDistance 设置合理（2-15）
- [ ] pursuitDistance 大于 watchDistance
- [ ] transferDis 符合怪物类型
- [ ] 与移动速度匹配

## 常见问题

### Q: 怪物攻击太快怎么办？
A: 增加 `attackInterval` 或 `nAttackSpeed` 的值。

### Q: 怪物攻击太慢怎么办？
A: 减少 `attackInterval` 或设置负的 `nAttackSpeed` 值。

### Q: 怪物发现距离太远怎么办？
A: 减少 `watchDistance` 的值。

### Q: 怪物追击距离太短怎么办？
A: 增加 `pursuitDistance` 的值。

### Q: 如何让怪物有传送技能？
A: 设置 `transferDis` 大于0的值。

## 总结

攻击速度和攻击范围的设置需要综合考虑：

1. **怪物类型** - 不同类型的怪物有不同的特点
2. **游戏平衡** - 确保不会过于强大或弱小
3. **玩家体验** - 提供合适的挑战和乐趣
4. **技术限制** - 考虑服务器性能和客户端表现

通过合理的配置，可以创造出丰富多样的怪物战斗体验，让游戏更加有趣和平衡。
