# 怪物配置参数详细说明

## Monster.config 参数说明

### 基础信息参数

| 参数名 | 类型 | 说明 | 示例值 | 备注 |
|--------|------|------|--------|------|
| entityid | int | 怪物唯一ID | 1 | 必须唯一，用于标识怪物 |
| entityType | int | 实体类型 | 1 | 1=普通怪，12=采集怪 |
| monsterType | int | 怪物类型 | 1 | 1=普通，2=精英，3=头目，4=Boss，5=护卫，6=练功师，7=仙女完美采集，8=砸罐子副本采集怪 |
| name | string | 怪物名称 | "鸡" | 显示在游戏中的名称 |
| level | int | 怪物等级 | 5 | 影响经验和掉落 |
| circle | int | 转生圈数 | 0 | 转生相关属性 |
| aiConfigId | int | AI配置ID | 1 | 关联AI.config中的配置 |
| propid | int | 属性配置ID | 1 | 关联Props.config中的配置 |
| flagid | int | 标志配置ID | 1 | 关联Flags.config中的配置 |

### 战斗相关参数

| 参数名 | 类型 | 说明 | 示例值 | 备注 |
|--------|------|------|--------|------|
| exp | int | 基础经验值 | 50 | 杀死怪物获得的基础经验 |
| attackInterval | int | 攻击间隔 | 2000 | 单位：毫秒 |
| skills | array | 技能列表 | {} | 怪物拥有的技能ID列表 |
| modelid | int | 外观模型ID | 30001 | 客户端显示的模型ID |

### 音效相关参数

| 参数名 | 类型 | 说明 | 示例值 | 备注 |
|--------|------|------|--------|------|
| attackMusicRate | int | 攻击音效概率 | 100 | 百分比，100=100% |
| dieMusicRate | int | 死亡音效概率 | 100 | 百分比 |
| targetMusicTate | int | 发现目标音效概率 | 100 | 百分比 |
| damageMusicRate | int | 受击音效概率 | 100 | 百分比 |

## 配置建议和注意事项

### 1. 数值平衡
- 生命值和攻击力要匹配怪物等级
- 经验值要符合游戏平衡
- 掉落概率要合理设置

### 2. AI行为
- 主动怪物的追击距离要适中
- 被动怪物的警戒距离要合理
- 巡逻半径要符合地图设计

### 3. 特殊标志
- 谨慎使用禁止类标志
- 合理设置脚本触发标志
- 注意标志之间的冲突

### 4. 性能考虑
- 控制对话触发频率
- 限制掉落物品数量
- 优化AI计算参数
