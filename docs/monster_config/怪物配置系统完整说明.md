# 怪物配置系统完整说明

## 概述

怪物配置系统是游戏中的核心配置模块，负责定义所有怪物的属性、行为、AI、掉落等各个方面。整个系统由多个配置文件组成，采用模块化设计，便于管理和维护。

## 配置文件结构

### 主要配置文件

```
data/config/monster/
├── Monster.config          # 怪物基础配置（主要配置文件）
├── Props.config            # 怪物属性配置
├── Flags.config            # 怪物标志配置
├── AI.config               # 怪物AI配置
├── StdMonster.config       # 标准怪物配置引用
├── StdMonster.txt          # 标准怪物详细配置
├── MonsterConfig.txt       # 怪物配置引用文件
├── talk/                   # 怪物对话配置目录
├── MonsterClass/           # 怪物分类配置目录
└── drops/                  # 怪物掉落配置目录
```

## 详细配置说明

### 1. Monster.config - 怪物基础配置

这是怪物配置的核心文件，定义了每个怪物的基本属性。

#### 主要字段说明：

- **entityid**: 怪物唯一ID
- **entityType**: 实体类型（1=普通怪，12=采集怪）
- **monsterType**: 怪物类型（1=普通，2=精英，3=头目，4=Boss，5=护卫，6=练功师，7=仙女完美采集，8=砸罐子副本采集怪）
- **name**: 怪物名称
- **level**: 怪物等级
- **circle**: 转生圈数
- **aiConfigId**: AI配置ID（关联AI.config）
- **propid**: 属性配置ID（关联Props.config）
- **flagid**: 标志配置ID（关联Flags.config）
- **exp**: 基础经验值
- **attackInterval**: 攻击间隔（毫秒）
- **skills**: 技能列表
- **modelid**: 外观模型ID
- **attackMusicRate**: 攻击音效概率
- **dieMusicRate**: 死亡音效概率
- **targetMusicTate**: 发现目标音效概率
- **damageMusicRate**: 受击音效概率

### 2. Props.config - 怪物属性配置

定义怪物的各种属性数值，包括生命值、攻击力、防御力等。

#### 主要属性字段：

- **nMaxHpAdd**: 最大生命值加成
- **nMaxMpAdd**: 最大魔法值加成
- **nPhysicalAttackMinAdd/MaxAdd**: 物理攻击力最小/最大值加成
- **nMagicAttackMinAdd/MaxAdd**: 魔法攻击力最小/最大值加成
- **nWizardAttackMinAdd/MaxAdd**: 道术攻击力最小/最大值加成
- **nPhysicalDefenceMinAdd/MaxAdd**: 物理防御力最小/最大值加成
- **nMagicDefenceMinAdd/MaxAdd**: 魔法防御力最小/最大值加成
- **nHitValueAdd**: 命中值加成
- **nDogValueAdd**: 闪避值加成
- **nMagicHitRateAdd**: 魔法命中率加成
- **nMagicDogerateAdd**: 魔法闪避率加成
- **fHpRateRenew**: 生命恢复率
- **fMpRateRenew**: 魔法恢复率
- **nHpRenew**: 生命恢复值
- **nMpRenew**: 魔法恢复值
- **nMoveOneSlotTime**: 移动一格所需时间（毫秒）
- **nAttackSpeed**: 攻击速度
- **aDeductDizzyRate**: 眩晕抗性
- **aDizzyTimeAbsorbAdd**: 眩晕时间吸收

### 3. Flags.config - 怪物标志配置

定义怪物的特殊行为和限制标志。

#### 主要标志说明：

- **DenyAutoAddMp**: 禁止自动恢复魔法
- **DenyDieSubExp**: 禁止死亡经验衰减
- **noReturnHome**: 不返回巢穴
- **AttackPet**: 攻击宠物
- **CanSeeHideActor**: 能看到隐身玩家
- **DenyMoveForbidBuff**: 禁止移动限制Buff
- **DenyMoveSpeedSlowBuff**: 禁止移动减速Buff
- **DenyBeCatch**: 不能被捕捉
- **DenyMove**: 不能移动
- **DenyBeMove**: 不能被移动
- **DenyBeAttack**: 不能被攻击
- **CanAttackMonster**: 能攻击怪物
- **DenyInitiativeAttackActor**: 禁止主动攻击玩家
- **AttackKiller**: 攻击红名玩家
- **DenyUseNearAttack**: 禁止近战攻击
- **ShowNameByNumber**: 按数字显示名称
- **showVestEntityName**: 显示实体名称
- **DenySetDir**: 禁止改变朝向
- **attackToScript**: 攻击时通知脚本

### 4. AI.config - 怪物AI配置

定义怪物的AI行为模式。

#### 主要AI参数：

- **aiType**: AI类型（1=被动，2=主动，3=宠物，4=护卫）
- **patrolRadius**: 巡逻半径
- **pursuitDistance**: 追击距离
- **watchDistance**: 警戒距离
- **leftHomeMaxDistance**: 离开巢穴最大距离
- **returnHomeRenewRate**: 返回巢穴恢复率
- **stopMinTime/MaxTime**: 停止时间范围
- **moveStopInterval**: 移动停止间隔
- **transferDis**: 传送距离
- **hitSetTargetRate**: 受击设置目标概率
- **battleFollowDis**: 战斗跟随距离
- **petFollowMasterTime**: 宠物跟随主人时间

### 5. 怪物对话系统 (talk/)

每个怪物可以配置对话内容，支持多种触发条件：

#### 对话类型：
- **type=0**: 空闲状态发言
- **type=1**: 发现目标发言
- **type=2**: 攻击发言（暂不支持）
- **type=3**: 被攻击发言
- **type=4**: 死亡发言
- **type=5**: 血量低于某值发言
- **type=6**: 创建时发言
- **type=7**: 消失时发言

#### 对话参数：
- **rate**: 发言概率（百分比）
- **param**: 特殊参数（如血量百分比）
- **bctype**: 广播类型（1=附近，2=场景，3=副本，4=世界，5=同阵营）
- **tiptype**: 提示类型（1=右侧提示，2=屏幕中央，4=弹出框，8=公告栏，16=短消息，32=温馨提示，64=GM提示，128=聊天栏）

### 6. 怪物掉落系统 (drops/)

定义怪物的掉落物品配置。

#### 掉落参数：
- **id**: 物品ID（0表示金币）
- **count**: 数量
- **strong**: 强化等级（负数表示随机范围）
- **quality**: 品质（负数表示随机范围）
- **propability**: 掉落概率（1=必掉，100=1%概率）
- **group**: 掉落组（同组物品按概率掉落）
- **LootTime**: 拾取延迟时间（秒）
- **ExpireTime**: 物品存活时间（秒）
- **startDate/overDate**: 掉落时间范围

## 配置使用流程

### 1. 创建新怪物

1. 在 `Monster.config` 中添加怪物基础信息
2. 在 `Props.config` 中配置怪物属性
3. 在 `Flags.config` 中设置怪物标志
4. 在 `AI.config` 中配置AI行为
5. 在 `talk/` 目录中配置对话（可选）
6. 在 `drops/` 目录中配置掉落（可选）

### 2. 怪物分类管理

- 使用 `MonsterClass/` 目录按类型分类管理怪物
- 通过 `MonsterConfig.txt` 引用各个分类文件
- 便于批量管理和维护

### 3. 配置验证

- 确保所有引用的ID都存在
- 检查数值范围的合理性
- 验证配置文件的语法正确性

## 最佳实践

### 1. 命名规范
- 怪物ID使用连续数字
- 配置文件使用有意义的名称
- 注释要清晰明了

### 2. 性能优化
- 合理设置AI参数，避免过度计算
- 控制掉落物品数量，避免性能问题
- 使用标志位优化特殊行为

### 3. 维护建议
- 定期备份配置文件
- 使用版本控制管理配置变更
- 建立配置变更记录

## 常见问题

### 1. 怪物不攻击玩家
检查 `Flags.config` 中的 `DenyInitiativeAttackActor` 和 `AI.config` 中的 `aiType` 设置。

### 2. 怪物不掉落物品
检查 `drops/` 目录中的掉落配置和概率设置。

### 3. 怪物AI异常
检查 `AI.config` 中的参数设置，特别是距离和概率参数。

### 4. 怪物属性异常
检查 `Props.config` 中的属性数值设置。

## 总结

怪物配置系统是一个复杂而完整的系统，通过模块化设计实现了高度的灵活性和可维护性。正确理解和配置各个模块是创建高质量游戏内容的关键。建议在修改配置前充分理解各个参数的作用，并在测试环境中验证配置的正确性。
