## 快速开始

### 1. 创建新怪物

```bash
# 1. 在 Monster.config 中添加基础信息
# 2. 在 Props.config 中配置属性
# 3. 在 Flags.config 中设置标志
# 4. 在 AI.config 中配置AI行为
# 5. 可选：配置对话和掉落
```

### 2. 配置验证

```bash
# 运行配置验证脚本
python config_validator.py

# 运行配置测试
python config_tester.py
```

### 3. 配置管理

```bash
# 备份配置
./backup_configs.sh

# 恢复配置
./restore_configs.sh <备份目录>

# 监控配置变更
python config_monitor.py
```


## 核心概念

### 1. 配置引用关系

```
Monster.config
├── aiConfigId → AI.config
├── propid → Props.config
└── flagid → Flags.config
```

### 2. 怪物类型

- **普通怪物** (monsterType=1): 基础怪物，适合新手
- **精英怪物** (monsterType=2): 强化怪物，提供更好奖励
- **头目怪物** (monsterType=3): 区域Boss，需要团队协作
- **Boss怪物** (monsterType=4): 世界Boss，顶级挑战
- **护卫怪物** (monsterType=5): 保护型怪物
- **练功师** (monsterType=6): 训练用怪物
- **采集怪** (monsterType=7,8): 资源采集怪物

### 3. AI行为类型

- **被动AI** (aiType=1): 不主动攻击，被攻击后反击
- **主动AI** (aiType=2): 主动攻击玩家
- **宠物AI** (aiType=3): 跟随主人，协助战斗
- **护卫AI** (aiType=4): 保护特定目标

## 配置参数速查

### 基础参数

| 参数 | 说明 | 示例值 |
|------|------|--------|
| entityid | 怪物唯一ID | 1 |
| name | 怪物名称 | "鸡" |
| level | 怪物等级 | 5 |
| exp | 基础经验 | 50 |
| modelid | 外观模型ID | 30001 |

### 属性参数

| 参数 | 说明 | 示例值 |
|------|------|--------|
| nMaxHpAdd | 最大生命值加成 | 5 |
| nPhysicalAttackMinAdd | 最小物理攻击 | 1 |
| nPhysicalAttackMaxAdd | 最大物理攻击 | 2 |
| nPhysicalDefenceMinAdd | 最小物理防御 | 0 |
| nPhysicalDefenceMaxAdd | 最大物理防御 | 0 |

### AI参数

| 参数 | 说明 | 示例值 |
|------|------|--------|
| aiType | AI类型 | 1 |
| pursuitDistance | 追击距离 | 18 |
| watchDistance | 警戒距离 | 4 |
| patrolRadius | 巡逻半径 | 1 |

### 标志参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| DenyMove | 禁止移动 | false |
| DenyBeAttack | 禁止被攻击 | false |
| AttackPet | 攻击宠物 | false |
| noReturnHome | 不返回巢穴 | false |

## 常见问题

### Q: 怪物不攻击玩家怎么办？
A: 检查 `Flags.config` 中的 `DenyInitiativeAttackActor` 和 `AI.config` 中的 `aiType` 设置。

### Q: 怪物不掉落物品怎么办？
A: 检查 `drops/` 目录中的掉落配置和概率设置。

### Q: 如何添加新怪物？
A: 按照配置模板在相应的配置文件中添加新条目，确保所有引用的ID都存在。

### Q: 配置修改后如何验证？
A: 使用配置验证脚本检查配置的完整性和正确性。
