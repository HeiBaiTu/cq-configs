# 怪物添加快速参考

## 概述

本文档提供添加新怪物的快速参考指南，包含所有必要的配置步骤和参数说明。

## 快速添加流程

### 1. 确定怪物基本信息

```lua
-- 怪物基本信息示例
怪物ID: 2000
怪物名称: "神龙守卫"
怪物等级: 80
怪物类型: 1 (普通), 2 (精英), 3 (头目), 4 (Boss)
外观模型: 32000
```

### 2. 修改配置文件

#### 2.1 Monster.config

```lua
[2000] = {
    entityid = 2000,
    entityType = 1,        -- 1=普通怪，12=采集怪
    monsterType = 1,       -- 1=普通，2=精英，3=头目，4=Boss
    name = "神龙守卫",
    level = 80,
    circle = 0,
    aiConfigId = 2000,     -- 关联AI配置
    propid = 2000,         -- 关联属性配置
    flagid = 2000,         -- 关联标志配置
    exp = 50000,           -- 基础经验值
    attackInterval = 1500, -- 攻击间隔（毫秒）
    skills = {2001, 2002}, -- 技能列表
    modelid = 32000,       -- 外观模型ID
    attackMusicRate = 100, -- 攻击音效概率
    dieMusicRate = 100,    -- 死亡音效概率
    targetMusicTate = 100, -- 发现目标音效概率
    damageMusicRate = 100, -- 受击音效概率
},
```

#### 2.2 Props.config

```lua
[2000] = {
    id = 2000,
    nMaxHpAdd = 50000,           -- 最大生命值加成
    nMaxMpAdd = 10000,           -- 最大魔法值加成
    nPhysicalAttackMinAdd = 800, -- 最小物理攻击
    nPhysicalAttackMaxAdd = 1200, -- 最大物理攻击
    nMagicAttackMinAdd = 800,   -- 最小魔法攻击
    nMagicAttackMaxAdd = 1200,  -- 最大魔法攻击
    nWizardAttackMinAdd = 800,  -- 最小道术攻击
    nWizardAttackMaxAdd = 1200, -- 最大道术攻击
    nPhysicalDefenceMinAdd = 400, -- 最小物理防御
    nPhysicalDefenceMaxAdd = 600, -- 最大物理防御
    nMagicDefenceMinAdd = 400,  -- 最小魔法防御
    nMagicDefenceMaxAdd = 600,  -- 最大魔法防御
    nHitValueAdd = 10000,       -- 命中值加成
    nDogValueAdd = 5000,        -- 闪避值加成
    nMagicHitRateAdd = 10000,  -- 魔法命中率加成
    nMagicDogerateAdd = 5000,  -- 魔法闪避率加成
    fHpRateRenew = 5,           -- 生命恢复率
    fMpRateRenew = 10,          -- 魔法恢复率
    nHpRenew = 200,             -- 生命恢复值
    nMpRenew = 100,             -- 魔法恢复值
    nMoveOneSlotTime = 1500,    -- 移动一格所需时间
    nAttackSpeed = 0,           -- 攻击速度
    aDeductDizzyRate = 50,      -- 眩晕抗性
    aDizzyTimeAbsorbAdd = 30,   -- 眩晕时间吸收
},
```

#### 2.3 Flags.config

```lua
[2000] = {
    id = 2000,
    DenyAutoAddMp = true,           -- 禁止自动恢复魔法
    DenyDieSubExp = true,           -- 禁止死亡经验衰减
    DenyMoveForbidBuff = true,      -- 禁止移动限制Buff
    DenyMoveSpeedSlowBuff = true,   -- 禁止移动减速Buff
    DenyBeCatch = true,             -- 不能被捕捉
    AttackPet = true,               -- 攻击宠物
    CanSeeHideActor = true,         -- 能看到隐身玩家
    noReturnHome = true,            -- 不返回巢穴
    showVestEntityName = true,      -- 显示实体名称
    DenyBeMove = true,              -- 不能被移动
    CanAttackMonster = true,        -- 能攻击怪物
    DenyInitiativeAttackActor = false, -- 允许主动攻击玩家
    AttackKiller = true,            -- 攻击红名玩家
    DenyUseNearAttack = false,      -- 允许近战攻击
    ShowNameByNumber = false,       -- 不按数字显示名称
    DenySetDir = false,             -- 允许改变朝向
    attackToScript = false,        -- 攻击时不通知脚本
},
```

## 配置参数速查

### 怪物类型 (monsterType)

| 值 | 类型 | 说明 |
|----|------|------|
| 1 | 普通 | 基础怪物，适合新手 |
| 2 | 精英 | 强化怪物，提供更好奖励 |
| 3 | 头目 | 区域Boss，需要团队协作 |
| 4 | Boss | 世界Boss，顶级挑战 |
| 5 | 护卫 | 保护型怪物 |
| 6 | 练功师 | 训练用怪物 |
| 7 | 仙女完美采集 | 资源采集怪物 |
| 8 | 砸罐子副本采集怪 | 副本采集怪物 |

### AI类型 (aiType)

| 值 | 类型 | 说明 |
|----|------|------|
| 1 | 被动AI | 不主动攻击，被攻击后反击 |
| 2 | 主动AI | 主动攻击玩家 |
| 3 | 宠物AI | 跟随主人，协助战斗 |
| 4 | 护卫AI | 保护特定目标 |

### 对话类型 (type)

| 值 | 类型 | 说明 |
|----|------|------|
| 0 | 空闲状态发言 | 怪物空闲时的对话 |
| 1 | 发现目标发言 | 发现玩家时的对话 |
| 2 | 攻击发言 | 攻击时的对话（暂不支持） |
| 3 | 被攻击发言 | 被攻击时的对话 |
| 4 | 死亡发言 | 死亡时的对话 |
| 5 | 血量低于某值发言 | 血量低于指定百分比时发言 |
| 6 | 创建时发言 | 怪物创建时的对话 |
| 7 | 消失时发言 | 怪物消失时的对话 |

### 广播类型 (bctype)

| 值 | 类型 | 说明 |
|----|------|------|
| 1 | 附近广播 | 附近玩家可见 |
| 2 | 场景广播 | 整个场景可见 |
| 3 | 副本广播 | 整个副本可见 |
| 4 | 世界广播 | 全服务器可见 |
| 5 | 同阵营广播 | 同阵营玩家可见 |

### 提示类型 (tiptype)

| 值 | 类型 | 说明 |
|----|------|------|
| 1 | 右侧提示 | 右侧提示框显示 |
| 2 | 屏幕中央 | 屏幕中央显示 |
| 4 | 弹出框 | 弹出对话框显示 |
| 8 | 公告栏 | 公告栏显示 |
| 16 | 短消息 | 短消息显示 |
| 32 | 温馨提示 | 温馨提示显示 |
| 64 | GM提示 | GM提示显示 |
| 128 | 聊天栏 | 聊天栏显示 |

## 常见问题

### 1. 怪物不显示
- 检查模型ID是否正确
- 验证配置文件语法
- 重启服务器

### 2. 怪物不攻击
- 检查aiType设置
- 检查DenyInitiativeAttackActor标志
- 调整警戒距离和追击距离

### 3. 怪物不掉落
- 检查掉落配置文件
- 验证掉落概率设置
- 确认物品ID存在

### 4. 怪物对话不触发
- 检查对话配置文件
- 调整对话概率
- 验证语言文件引用

## 总结

添加新怪物需要修改4个核心配置文件：
1. Monster.config - 怪物基础配置
2. Props.config - 怪物属性配置
3. Flags.config - 怪物标志配置
4. AI.config - 怪物AI配置

可选配置：
- talk/M{ID}.txt - 对话配置
- drops/drops{ID}.txt - 掉落配置

关键是要保持配置的一致性和完整性，建议先在测试环境验证，确认无误后再部署到生产环境。
