# 怪物配置文件结构说明

## 配置文件关系图

```
怪物配置系统
├── 主配置文件
│   ├── Monster.config (怪物基础信息)
│   ├── Props.config (属性配置)
│   ├── Flags.config (标志配置)
│   └── AI.config (AI行为配置)
│
├── 引用配置文件
│   ├── StdMonster.config (标准怪物引用)
│   ├── StdMonster.txt (标准怪物详细配置)
│   └── MonsterConfig.txt (怪物分类引用)
│
└── 子配置目录
    ├── talk/ (对话配置)
    │   ├── M0000.txt ~ M1211.txt
    │   └── (按怪物ID命名的对话文件)
    │
    ├── MonsterClass/ (怪物分类)
    │   └── MonsterSmple.txt (示例配置)
    │
    └── drops/ (掉落配置)
        ├── drops1.txt ~ drops59.txt
        └── dropsdropsID.txt (掉落ID配置)
```

## 配置文件依赖关系

### 1. 核心依赖链
```
Monster.config
├── 引用 aiConfigId → AI.config
├── 引用 propid → Props.config
└── 引用 flagid → Flags.config
```

### 2. 扩展配置
```
Monster.config
├── 可选引用 talk → talk/M{ID}.txt
├── 可选引用 drops → drops/drops{ID}.txt
└── 可选引用 MonsterClass → MonsterClass/*.txt
```

## 配置数据流向

### 1. 怪物创建流程
```
1. 读取 Monster.config 获取基础信息
2. 根据 aiConfigId 读取 AI.config 获取行为配置
3. 根据 propid 读取 Props.config 获取属性配置
4. 根据 flagid 读取 Flags.config 获取标志配置
5. 可选读取 talk/M{ID}.txt 获取对话配置
6. 可选读取 drops/drops{ID}.txt 获取掉落配置
```

### 2. 配置优先级
```
1. Monster.config 中的直接配置 (最高优先级)
2. Props.config 中的属性配置
3. Flags.config 中的标志配置
4. AI.config 中的AI配置
5. 子配置文件中的扩展配置 (最低优先级)
```

## 文件命名规范

### 1. 主配置文件
- `Monster.config` - 怪物基础配置
- `Props.config` - 属性配置
- `Flags.config` - 标志配置
- `AI.config` - AI配置

### 2. 对话文件
- 格式：`M{怪物ID}.txt`
- 示例：`M0001.txt` (怪物ID为1的对话配置)

### 3. 掉落文件
- 格式：`drops{掉落组ID}.txt`
- 示例：`drops1.txt` (掉落组1的配置)

### 4. 分类文件
- 格式：`Monster{分类ID}.txt`
- 示例：`Monster1.txt` (分类1的怪物配置)

## 配置验证规则

### 1. ID引用验证
- Monster.config 中的 aiConfigId 必须在 AI.config 中存在
- Monster.config 中的 propid 必须在 Props.config 中存在
- Monster.config 中的 flagid 必须在 Flags.config 中存在

### 2. 数值范围验证
- 等级范围：1-999
- 概率范围：0-100
- 时间范围：毫秒单位，合理范围
- 距离范围：游戏内坐标单位

### 3. 文件完整性验证
- 所有引用的子配置文件必须存在
- 配置文件语法必须正确
- 必填字段不能为空

## 配置管理建议

### 1. 版本控制
- 使用Git等版本控制系统管理配置文件
- 每次修改前创建备份
- 记录配置变更日志

### 2. 测试流程
- 在测试环境中验证配置
- 进行功能测试和性能测试
- 确认配置正确后再部署到生产环境

### 3. 维护策略
- 定期检查配置文件的一致性
- 清理无用的配置项
- 优化配置结构，提高可读性

## 常见配置错误

### 1. 引用错误
- 引用了不存在的ID
- 引用了错误的文件路径
- 循环引用导致的死锁

### 2. 数值错误
- 超出合理范围的数值
- 负数或零值的不当使用
- 单位不匹配（毫秒vs秒）

### 3. 语法错误
- 缺少必要的逗号或括号
- 字符串未正确引用
- 注释格式错误

## 配置优化建议

### 1. 性能优化
- 合理设置AI参数，避免过度计算
- 控制掉落物品数量
- 优化对话触发频率

### 2. 可维护性
- 使用有意义的命名
- 添加详细的注释
- 采用模块化设计

### 3. 扩展性
- 预留配置项用于未来扩展
- 使用灵活的配置结构
- 支持动态配置加载
