# 商城商品配置问题分析

## 问题描述

主商城中存在商品显示与实际购买不一致的问题：
- **显示问题**: 商店界面显示"护身碎片"和"内功丹"
- **实际获得**: 购买后实际获得的是"挂机卷轴"

## 问题根源

**前后端配置不一致**：
- 后端配置的商品ID与前端配置的商品ID不匹配
- 导致客户端显示的商品与实际购买获得的商品不同

## 影响分析

### 对玩家的影响
1. **用户体验问题**: 玩家看到的是护身碎片/内功丹，但买到的是挂机卷轴
2. **功能混淆**: 护身碎片用于提升神戒，挂机卷轴用于经验加成，功能完全不同
3. **信任问题**: 可能导致玩家对商城系统的信任度下降

### 对游戏的影响
1. **经济平衡**: 挂机卷轴是消耗品，护身碎片是材料，价格体系可能不合理
2. **功能定位**: 补给标签页应该主要销售消耗品，而不是材料
3. **数据统计**: 可能导致商品销售数据统计不准确

## 修复方案

### 方案1: 修改后端配置（推荐）

**优点**:
- 保持前端显示不变，用户体验一致
- 护身碎片和内功丹更适合作为特殊材料，通过活动获得
- 减少客户端更新需求

**缺点**:
- 需要重启服务器
- 可能影响现有的商品销售数据

**修改内容**:
```lua
-- 修改 data/config/shop/shop.config
[24] = {
    shoptype = 1,
    Tabshop = 3,
    shopid = 24,
    shop = {type=0,id=1015,count=1},  -- 改为内功丹
    price = {type=4,id=4,count=500},
    levellimit = 1,
    reincarnationlimit = 0,
    daylimit = 0,
    buytype = {},
},
[25] = {
    shoptype = 1,
    Tabshop = 3,
    shopid = 25,

    price = {type=4,id=4,count=1000},
```

## 推荐方案

**建议采用方案2（修改前端配置）**，理由如下：

1. **功能定位合理**: 挂机卷轴属于消耗品，更适合放在补给标签页
2. **用户体验**: 玩家购买挂机卷轴后能立即使用，体验更好
3. **系统稳定性**: 保持后端逻辑不变，减少服务器重启风险
4. **数据一致性**: 避免商品销售数据统计混乱
