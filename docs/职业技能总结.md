# 职业技能总结

## 概述
本文档总结了游戏中三个职业的所有技能配置，包括战士、法师和道士的技能详细信息。

## 职业分类

### 1. 战士职业 (vocation: 1)
战士是近战物理攻击职业，拥有强大的近战技能和切换技能。

#### 基础技能
- **基本剑术** (ID: 1) - 被动技能，已删除
- **攻杀剑术** (ID: 2) - 被动技能，12级自动学习
- **刺杀剑术** (ID: 3) - 主动技能，7级自动学习，切换技能
- **半月弯刀** (ID: 4) - 主动技能，23级自动学习，切换技能
- **野蛮冲撞** (ID: 5) - 主动技能，30级自动学习
- **烈火剑法** (ID: 6) - 主动技能，35级自动学习，切换技能
- **狮子吼** (ID: 7) - 主动技能，43级学习，已删除
- **逐日剑法** (ID: 8) - 主动技能，47级自动学习，切换技能

#### 怒之系列技能
- **怒之半月** (ID: 81) - 被动技能，强化半月弯刀
- **怒之烈火** (ID: 82) - 被动技能，强化烈火剑法
- **怒之逐日** (ID: 83) - 被动技能，强化逐日剑法

#### 特殊技能
- **雷霆一击** (ID: 89) - 主动技能，特殊学习条件

- **火墙** (ID: 14) - 主动技能，24级自动学习
- **疾光电影** (ID: 15) - 主动技能，已删除

- **魔法盾** (ID: 17) - 主动技能，30级自动学习
- **冰咆哮** (ID: 18) - 主动技能，35级自动学习
- **寒冰掌** (ID: 19) - 主动技能，36级学习，已删除
- **灭天火** (ID: 20) - 主动技能，已删除
- **流星火雨** (ID: 21) - 主动技能，47级自动学习

#### 怒之系列技能

- **怒之冰咆** (ID: 85) - 被动技能，强化冰咆哮

#### 特殊技能

- **气功波** (ID: 31) - 主动技能，38级自动学习
- **无极真气** (ID: 32) - 主动技能，已删除

## 技能类型说明

### 技能类型 (skillType)
- **0**: 被动技能
- **1**: 主动技能（物理）
- **2**: 主动技能（魔法）

### 技能分类 (skillClass)
- **1**: 基础技能
- **2**: 高级技能
- **3**: 特殊技能

### 学习方式
- **自动学习**: 达到指定等级自动获得
- **技能书学习**: 需要获得相应的技能书
- **特殊条件**: 需要满足特殊条件才能学习

### 技能状态
- **正常使用**: 技能可以正常使用
- **已删除/禁用**: 技能被禁用，无法使用

## 注意事项

1. 部分技能当前处于禁用状态，可能需要特殊配置才能启用
2. 怒之系列技能需要特殊条件才能学习
3. 雷霆一击技能所有职业都有，但需要特殊学习条件
4. 技能的学习等级和效果可能会根据游戏版本有所调整
