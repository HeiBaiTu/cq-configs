# 后端配置修改详细指南

## 概述

本指南详细说明如何修改后端配置文件来添加神龙装备。所有修改都需要在 `data/config/` 目录下的相应文件中进行。

## 需要修改的配置文件列表

### 1. 装备基础配置
- **文件**: `data/config/item/StdItems.config`
- **作用**: 定义装备的基本属性和参数

### 2. 套装配置
- **文件**: `data/config/SuitConfig.config`
- **作用**: 定义套装属性和套装效果

### 3. 装备合成配置
- **文件**: `data/config/Merge/ItemMerge.config`
- **作用**: 定义装备合成配方

### 4. 回收配置
- **文件**: `data/config/setting/RecyclingSetting.config`
- **作用**: 定义装备回收选项
