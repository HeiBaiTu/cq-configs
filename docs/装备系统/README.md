## 需要修改的配置文件

### 后端配置文件
- `data/config/item/StdItems.config` - 装备基础配置
- `data/config/SuitConfig.config` - 套装配置
- `data/config/Merge/ItemMerge.config` - 合成配置
- `data/config/setting/RecyclingSetting.config` - 回收配置

### 前端配置文件
- `split_configs/StdItems.json` - 装备配置
- `split_configs/SuitConfig.json` - 套装配置
- `split_configs/ItemMergeConfig.json` - 合成配置
- `split_configs/RecyclingSettingConfig.json` - 回收配置

## 注意事项

### 1. 配置一致性
- 前后端配置必须完全一致
- 所有属性值必须相同
- 图标ID必须匹配

### 2. 性能考虑
- 新装备属性较高，可能影响游戏平衡
- 建议分阶段开放
- 监控服务器性能指标

### 3. 数据安全
- 定期备份配置文件
- 测试环境充分验证
- 准备回滚方案

### 4. 用户体验
- 提供清晰的装备获取途径
- 确保合成材料容易获得
- 平衡装备获取难度

## 总结

通过这套文档，您可以完整地添加比金牛属性更高的新装备。所有配置修改都需要前后端同步，建议先在测试环境充分验证，确认无误后再部署到生产环境。
