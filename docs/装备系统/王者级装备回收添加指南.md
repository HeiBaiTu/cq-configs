## 配置参数说明

### 回收设置参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| id | 数字 | 回收分类ID，用于区分不同的回收分类 |
| idx | 数字 | 分类内索引，用于排序 |
| optionid | 数字 | 选项ID，用于客户端识别 |
| value | 数字 | 默认值，0=不回收，1=回收 |
| name | 字符串 | 显示名称 |
| tips | 字符串 | 提示信息 |
| title | 字符串 | 分类标题 |
| itemlevel | 数字 | 装备等级标识，用于匹配装备 |
| showQuality | 数字 | 显示品质，影响UI显示效果 |

### 装备等级标识规则

- **114**: 王者装备等级
- **115**: 炎之王者装备等级
- 建议使用114-115作为王者级装备等级标识

### 选项ID分配

- **62**: 王者装备回收选项
- **63**: 炎之王者装备回收选项
- 建议使用62-63作为王者级装备回收选项ID

## 注意事项

### 1. 配置同步性

- 前后端配置必须保持同步
- 前端修改后需要清除浏览器缓存
- 后端修改后需要重启服务器

### 2. 装备等级标识

- 确保 `itemlevel` 的唯一性
- 建议使用114-115作为王者级装备等级
- 避免与现有装备等级冲突

### 3. 选项ID唯一性

- 确保 `optionid` 的唯一性
- 建议使用62-63作为王者级装备回收选项ID
- 避免与现有选项ID冲突

### 4. 用户体验

- 王者级装备价值较高，建议默认不开启回收
- 提供清晰的提示信息，提醒玩家谨慎使用
- 考虑装备的稀有度和价值

### 5. 性能考虑

- 王者级装备回收频率较低，对性能影响较小
- 合理设置回收触发条件
- 考虑服务器性能影响
