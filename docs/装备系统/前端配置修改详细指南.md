# 前端配置修改详细指南

## 概述

本指南详细说明如何修改前端配置文件来添加神龙装备。所有修改都需要在 `split_configs/` 目录下的相应JSON文件中进行。

## 需要修改的配置文件列表

### 1. 装备基础配置
- **文件**: `split_configs/StdItems.json`
- **作用**: 定义装备的基本属性和参数（前端显示）

### 2. 套装配置
- **文件**: `split_configs/SuitConfig.json`
- **作用**: 定义套装属性和套装效果（前端显示）

### 3. 装备合成配置
- **文件**: `split_configs/ItemMergeConfig.json`
- **作用**: 定义装备合成配方（前端显示）

### 4. 回收配置
- **文件**: `split_configs/RecyclingSettingConfig.json`
- **作用**: 定义装备回收选项（前端显示）
