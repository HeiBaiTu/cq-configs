# 新装备添加完整指南

## 概述

本指南详细说明如何在金牛炎装备之上添加一套新的装备。基于对现有装备体系的分析，提供完整的配置修改步骤。

## 装备等级体系分析

### 当前装备等级分布
- **itemlevel = 117**: 金牛炎装备（当前最高等级）
- **itemlevel = 118**: 天龙装备（已存在，但可能未完全实现）

### 建议的新装备等级
- **itemlevel = 119**: 新装备等级（建议名称：神龙装备）

## 需要修改的配置文件

### 1. 后端配置文件

#### 1.1 装备基础配置
**文件**: `data/config/item/StdItems.config`

需要添加的装备类型：
- 头盔 (type = 3)
- 腰带 (type = 8) 
- 靴子 (type = 9)
- 衣服 (type = 4, 5, 6) - 战士、法师、道士
- 武器 (type = 1, 2, 3) - 战士、法师、道士
- 项链 (type = 4)
- 手镯 (type = 6)
- 戒指 (type = 7)

#### 1.2 套装配置
**文件**: `data/config/SuitConfig.config`

需要添加新套装的配置，包括：
- 套装名称
- 套装属性
- 套装件数要求

#### 1.3 装备合成配置
**文件**: `data/config/Merge/ItemMerge.config`

需要添加新装备的合成配方，通常是从金牛炎装备合成到新装备。

#### 1.4 回收配置
**文件**: `data/config/setting/RecyclingSetting.config`

需要添加新装备的回收选项。

### 2. 前端配置文件

#### 2.1 装备配置
**文件**: `split_configs/StdItems.json`

需要同步添加所有新装备的前端配置。

#### 2.2 套装配置
**文件**: `split_configs/SuitConfig.json`

需要同步添加套装配置。

#### 2.3 回收配置
**文件**: `split_configs/RecyclingSettingConfig.json`

需要添加新装备的回收选项。

## 注意事项

### 1. ID冲突检查
- 确保所有新ID不与现有ID冲突
- 建议使用ID范围：850-870

### 2. 图标资源
- 需要为所有新装备分配图标ID
- 确保图标资源文件存在

### 3. 前后端同步
- 所有配置修改都需要前后端同步
- 建议使用配置分割工具自动生成前端配置

### 4. 测试验证
- 在测试环境先验证所有功能
- 检查装备属性显示是否正确
- 验证合成、回收等功能

### 5. 数据库更新
- 新装备可能需要数据库表结构更新
- 检查是否有相关的数据库配置

## 总结

添加新装备需要修改多个配置文件，包括：
1. 装备基础配置 (StdItems.config)
2. 套装配置 (SuitConfig.config)  
3. 合成配置 (ItemMerge.config)
4. 回收配置 (RecyclingSetting.config)
5. 对应的前端JSON配置文件

关键是要保持前后端配置的一致性，并确保所有ID不冲突。建议先在测试环境验证，确认无误后再部署到正式环境。
