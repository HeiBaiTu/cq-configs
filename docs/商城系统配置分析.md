# 商城系统配置分析

## 概述
本文档详细分析游戏中的商城系统配置，包括主商城、行会商店、NPC商店等各种商店类型的配置结构和设置方法。

## 商城系统架构

### 商店类型分类
1. **主商城** (shoptype = 1): 元宝商城，支持多种货币
2. **行会商店** (shoptype = 2): 使用行会贡献购买
3. **NPC商店** (shoptype = 3): 小贩，使用绑定金币
4. **杂货铺** (shoptype = 4): 使用绑定金币购买药品和卷轴
5. **活跃商城** (shoptype = 5): 使用活跃度购买
6. **战令商店** (shoptype = 6): 使用战令积分购买

## 商城配置参数详解

### 商品配置参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| shoptype | 数字 | 商店类型ID |
| Tabshop | 数字 | 标签页ID |
| shopid | 数字 | 商品唯一ID |
| shop | 对象 | 商品信息 {type, id, count} |
| price | 对象 | 价格信息 {type, id, count} |
| levellimit | 数字 | 等级限制 |
| reincarnationlimit | 数字 | 转生限制 |
| daylimit | 数字 | 每日购买限制 (0=无限制) |
| buytype | 数组 | 购买条件限制 |
| batchbuy | 数字 | 是否支持批量购买 (0/1) |
| Maxbatchbuy | 数字 | 最大批量购买数量 |
| guildLevel | 数字 | 行会等级要求 |
| statictype | 数字 | 统计类型 |
| tips | 字符串 | 提示信息 |

### 购买条件 (buytype)

```lua
buytype = {
    {
        type = 3,  -- 条件类型
        limit = {
            {value = 0, times = 1},    -- 普通玩家限制1次
            {value = 8, times = -1}    -- VIP8玩家无限制
        }
    }
}
```

### 商店标签页参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| Tabshop | 数字 | 标签页ID |
| shoptype | 数字 | 商店类型 |
| name | 字符串 | 标签页名称 |
| tabname | 字符串 | 标签页显示名称 |
| title | 字符串 | 商店标题 |
| dealtype | 字符串 | 交易类型描述 |
| sctype | 数字 | 商店分类类型 |

## 如何添加新的商城商品

### 方法1: 添加新的商品到现有标签页

#### 1. 修改后端配置

在 `data/config/shop/shop.config` 中添加新商品：

```lua
[1] = {  -- 主商城
    [1] = {  -- 功能标签页
        [新商品ID] = {
            shoptype = 1,
            Tabshop = 1,
            shopid = 新商品ID,
            shop = {type=0,id=物品ID,count=数量},
            price = {type=4,id=4,count=价格},
            levellimit = 1,
            reincarnationlimit = 0,
            daylimit = 0,
            buytype = {},
        },
    },
}
```

#### 2. 修改前端配置

在 `split_configs/ShopConfig.json` 中添加对应配置：

```json
{
  "1": {
    "1": {
      "新商品ID": {
        "Tabshop": 1,
        "buytype": [],
        "daylimit": 0,
        "levellimit": 1,

          "id": 物品ID,

  }
```

## 修改步骤

### 1. 备份原文件
```bash
# 备份后端配置文件
cp data/config/shop/shop.config data/config/shop/shop.config.backup
cp data/config/store/NPCStore.txt data/config/store/NPCStore.txt.backup

# 备份前端配置文件
cp split_configs/ShopConfig.json split_configs/ShopConfig.json.backup
cp split_configs/ShopnameConfig.json split_configs/ShopnameConfig.json.backup
cp split_configs/ShoptagConfig.json split_configs/ShoptagConfig.json.backup
```

### 2. 修改后端配置
按照上述方案修改 `data/config/shop/` 和 `data/config/store/` 目录下的配置文件

### 3. 修改前端配置
按照上述方案修改 `split_configs/` 目录下的配置文件

### 4. 重启服务器
让后端配置生效

### 5. 清除客户端缓存
让前端配置生效

### 6. 测试验证
在游戏中测试商城功能是否正常工作

## 注意事项

### 1. 配置同步性
- 前后端配置必须保持同步
- 前端修改后需要清除浏览器缓存
- 后端修改后需要重启服务器

### 2. 商品ID唯一性
- 确保 `shopid` 的唯一性
- 避免与现有商品ID冲突

### 3. 货币类型
- 确保使用的货币类型存在
- 新货币类型需要先在货币系统中定义

### 4. 物品ID有效性
- 确保商品对应的物品ID在物品配置中存在
- 验证物品的可用性和属性

### 5. 价格合理性
- 设置合理的价格，避免影响游戏经济平衡
- 考虑不同货币的兑换比例

### 6. 购买限制
- 合理设置购买限制，避免影响游戏体验
- 考虑VIP特权和特殊活动

## 总结

商城系统通过多层配置结构管理不同类型的商店和商品：

1. **商店类型**: 通过 `shoptype` 区分不同类型的商店
2. **标签页分类**: 通过 `Tabshop` 管理商店内的商品分类
3. **商品配置**: 通过 `shopid` 管理具体的商品信息
4. **货币系统**: 支持多种货币类型的购买
5. **购买限制**: 支持等级、转生、每日限制等多种限制条件

通过合理配置这些参数，可以创建功能完善的商城系统，为玩家提供便捷的购买体验。
