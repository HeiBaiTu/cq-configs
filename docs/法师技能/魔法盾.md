# 魔法盾

## 技能基本信息
- **技能ID**: 17
- **技能名称**: 魔法盾
- **职业**: 法师 (vocation: 2)
- **技能类型**: 主动技能 (skillType: 2)
- **技能分类**: 基础技能 (skillClass: 1)
- **学习等级**: 30级自动学习
- **状态**: 正常使用

## 技能配置详情
```lua
[17] = {
    id = 17,
    name = "魔法盾",
    vocation = 2,
    skillType = 2,           -- 主动技能
    skillClass = 1,          -- 基础技能类
    commonCd = 0,            -- 无公共冷却

    specialBuffCond = 0,     -- 无特殊BUFF条件

    isAutoLearn = true,      -- 自动学习
    autoLearnSkillLvl = 30,  -- 30级自动学习
```

## 技能说明
魔法盾是法师的防御技能，30级时自动学习。该技能可以为自己创造一个魔法护盾，吸收一定量的伤害，是法师重要的保命技能。

## 技能特点
- **伤害吸收**: 吸收一定量的伤害
- **持续效果**: 护盾会持续一段时间
- **防御技能**: 主要用于保护自己
- **无冷却**: 无公共冷却时间

## 使用场景
- **PK战斗**: 减少受到的伤害
- **打BOSS**: 提高生存能力
- **危险情况**: 在生命危险时使用
- **团队配合**: 为队友提供保护

## 使用技巧
- 在战斗开始前就开启魔法盾
- 注意护盾的持续时间
- 可以配合其他技能使用
- 在PK中持续保持护盾状态

## 学习建议
- 30级时自动学习
- 建议在战斗前就开启
- 是法师重要的保命技能
