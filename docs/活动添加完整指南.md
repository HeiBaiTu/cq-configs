# 活动添加完整指南

## 概述

本指南详细说明如何在游戏中添加新的活动。基于对现有活动配置的分析，提供完整的活动添加步骤和配置方法。

## 活动系统架构分析

### 活动配置层次结构

1. **活动总表** (`Activities.config`) - 定义活动基本信息
2. **活动详细配置** (`ActivityXXXConfig.config`) - 定义具体活动内容
3. **活动设置** (`ActivitysetConfig.config`) - 定义活动特殊设置
4. **前端配置** (`split_configs/` 目录下的JSON文件) - 前端显示配置

### 活动类型分析

从现有配置中发现的活动类型：

| ActivityType | 活动类型 | 说明 | 示例 |
|--------------|----------|------|------|
| 3 | 竞技活动 | 玩家对战类活动 | 竞技大乱斗 |
| 5 | 夺宝活动 | 地图夺宝类活动 | 地下夺宝、石墓夺宝 |
| 6 | 怪物活动 | 特殊怪物刷新 | 散财鹿 |
| 7 | 副本活动 | 特殊副本开放 | 个人副本 |
| 8 | 充值活动 | 充值相关活动 | 累计充值 |
| 9 | 签到活动 | 每日签到 | 签到奖励 |
| 10 | 限时活动 | 限时开放活动 | 限时商城 |
| 11 | 任务活动 | 任务类活动 | 每日任务 |
| 16 | 排行榜活动 | 排行榜相关 | 战力排行 |
| 17-22 | 特殊活动 | 各种特殊活动 | 战令、节日活动 |

## 具体实现步骤

### 步骤1: 确定活动类型和ID

#### 1.1 选择活动类型
根据活动性质选择合适的 `ActivityType`：
- **竞技类**: ActivityType = 3
- **夺宝类**: ActivityType = 5  
- **怪物类**: ActivityType = 6
- **副本类**: ActivityType = 7
- **充值类**: ActivityType = 8
- **签到类**: ActivityType = 9
- **限时类**: ActivityType = 10
- **任务类**: ActivityType = 11

#### 1.2 分配活动ID
建议使用ID范围：100-200（需要确认当前最大ID）

### 步骤2: 设计活动配置

#### 2.1 活动基本信息设计

```lua
-- 示例：新活动配置
[100] = {
    Id = 100,
    ActivityType = 10,  -- 限时活动
    ActivityName = "限时双倍经验",
    TimeType = 3,  -- 时间类型：3=每日固定时间
    TimeDetail = {
        [1] = {StartTime="0-10:00", EndTime="0-12:00"},
        [2] = {StartTime="0-20:00", EndTime="0-22:00"},
    },
    Popup = true,  -- 是否弹窗提示
    TipsLevelLimit = {level=1, zsLevel=0},  -- 等级限制
},
```

#### 2.2 时间类型说明

| TimeType | 说明 | 示例 |
|----------|------|------|
| 1 | 开服后固定天数 | 开服第3天开始 |
| 2 | 每周固定时间 | 每周一、三、五 |
| 3 | 每日固定时间 | 每天10:00-12:00 |
| 4 | 一次性活动 | 特定日期时间 |

### 步骤3: 修改配置文件

#### 3.1 修改 Activities.config

在文件末尾添加新活动：

```lua
[100] = {
    Id = 100,
    ActivityType = 10,
    ActivityName = "限时双倍经验",
    TimeType = 3,
    TimeDetail = {
        [1] = {StartTime="0-10:00", EndTime="0-12:00"},
        [2] = {StartTime="0-20:00", EndTime="0-22:00"},
    },
    Popup = true,
    TipsLevelLimit = {level=1, zsLevel=0},
},
```

#### 3.2 创建活动详细配置

创建新文件 `data/config/activity/Activity100Config.config`：

```lua
-- 限时双倍经验活动配置
Activity100Config={
[100] = {
    Id = 100,
    name = "限时双倍经验",
    description = "活动期间打怪获得双倍经验",
    effectType = 1,  -- 效果类型：1=经验加成
    effectValue = 200,  -- 效果值：200=200%经验（双倍）
    levelLimit = {min=1, max=999},  -- 等级限制
    mapLimit = {-1},  -- 地图限制：-1=全地图
    tips = "活动期间打怪获得双倍经验奖励！",
},
}
```

#### 3.3 修改 ActivitysetConfig.config（如需要）

如果活动需要特殊设置：

```lua
[100] = {
    [1] = {
        ID = 100,
        number = 1,
        openday = 1,  -- 开服第几天开放
        tips = 500,  -- 提示文本ID
        timer = 24,  -- 活动持续时间（小时）
    },
},
```

## 注意事项

### 1. ID冲突检查
- 确保活动ID不与现有ID冲突
- 建议使用ID范围：100-200

### 2. 时间格式
- 每日时间格式：`"0-10:00"` (星期0=周日，10:00=时间)
- 特定日期格式：`"2024-01-01 00:00"`
- 开服天数格式：`"1"` (开服第1天)

### 3. 前后端同步
- 所有配置修改都需要前后端同步
- 建议使用配置分割工具自动生成前端配置

### 4. 活动测试
- 在测试环境先验证活动功能
- 检查时间触发是否正确
- 验证奖励发放是否正常

### 5. 数据库更新
- 某些活动可能需要数据库表结构更新
- 检查是否有相关的数据库配置

## 活动类型详细说明

### 竞技活动 (ActivityType = 3)
- 玩家对战类活动
- 需要配置对战规则、奖励等
- 示例：竞技大乱斗

### 夺宝活动 (ActivityType = 5)
- 地图夺宝类活动
- 需要配置地图、宝箱、奖励等
- 示例：地下夺宝、石墓夺宝

### 怪物活动 (ActivityType = 6)
- 特殊怪物刷新活动
- 需要配置怪物、刷新时间、奖励等
- 示例：散财鹿

### 副本活动 (ActivityType = 7)
- 特殊副本开放活动
- 需要配置副本、进入条件、奖励等
- 示例：个人副本

### 充值活动 (ActivityType = 8)
- 充值相关活动
- 需要配置充值档位、奖励等
- 示例：累计充值

### 签到活动 (ActivityType = 9)
- 每日签到活动
- 需要配置签到奖励、连续奖励等
- 示例：每日签到

### 限时活动 (ActivityType = 10)
- 限时开放活动
- 可以配置各种限时效果
- 示例：限时双倍经验

### 任务活动 (ActivityType = 11)
- 任务类活动
- 需要配置任务内容、奖励等
- 示例：每日任务

## 总结

添加新活动需要修改多个配置文件：

1. **活动总表** (`Activities.config`) - 定义活动基本信息
2. **活动详细配置** (`ActivityXXXConfig.config`) - 定义具体活动内容
3. **活动设置** (`ActivitysetConfig.config`) - 定义活动特殊设置
4. **前端配置** (对应的JSON文件) - 前端显示配置

关键是要选择合适的活动类型，正确配置时间触发，并确保前后端配置的一致性。建议先在测试环境验证，确认无误后再部署到正式环境。
