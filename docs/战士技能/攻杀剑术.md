# 攻杀剑术

## 技能基本信息
- **技能ID**: 2
- **技能名称**: 攻杀剑术
- **职业**: 战士 (vocation: 1)
- **技能类型**: 被动技能 (skillType: 0)
- **技能分类**: 基础技能 (skillClass: 1)
- **学习等级**: 12级自动学习
- **状态**: 正常使用

## 技能配置详情
```lua
[2] = {
    id = 2,
    name = "攻杀剑术",
    vocation = 1,
    skillType = 0,           -- 被动技能
    skillClass = 1,          -- 基础技能类
    commonCd = 750,          -- 公共冷却时间750ms
    isSwitch = false,        -- 非切换技能
    specialBuffCond = 0,     -- 无特殊BUFF条件
    needCalPassiveProperty = false,  -- 不需要计算被动属性
    priority = 3,            -- 优先级3
    isAutoLearn = true,      -- 自动学习
    autoLearnSkillLvl = 12,  -- 12级自动学习
    direction = 1,           -- 需要方向
    action = 1,              -- 动作类型
}
```

## 技能说明
攻杀剑术是战士在12级时自动学习的重要被动技能。该技能提供额外的攻击力加成，是战士前期提升输出的重要技能。

## 技能特点
- **自动学习**: 12级时自动获得
- **被动效果**: 持续提供攻击力加成
- **冷却时间**: 750ms公共冷却
- **优先级**: 3级优先级

## 学习建议
- 12级时自动学习，无需额外操作
- 建议优先提升该技能等级以获得更好的效果
