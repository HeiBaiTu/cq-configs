# 基本剑术

## 技能基本信息
- **技能ID**: 1
- **技能名称**: 基本剑术
- **职业**: 战士 (vocation: 1)
- **技能类型**: 被动技能 (skillType: 0)
- **技能分类**: 基础技能 (skillClass: 1)
- **学习方式**: 需要技能书学习
- **状态**: 已删除/禁用 (isDelete: true)

## 技能配置详情
```lua
[1] = {
    id = 1,
    name = "基本剑术",
    vocation = 1,
    skillType = 0,           -- 被动技能
    skillClass = 1,          -- 基础技能类
    commonCd = 0,            -- 无冷却时间
    isSwitch = false,        -- 非切换技能
    specialBuffCond = 0,     -- 无特殊BUFF条件
    needCalPassiveProperty = true,  -- 需要计算被动属性
    priority = 0,            -- 优先级
    isAutoLearn = false,     -- 不自动学习
    direction = 0,           -- 无方向要求
    action = 1,              -- 动作类型
    isDelete = true,         -- 已删除/禁用
}
```

## 技能说明
基本剑术是战士的基础被动技能，虽然当前在配置中被标记为删除状态，但作为战士职业的基础技能，它通常提供基础的攻击力加成或命中率提升。

## 注意事项
- 该技能当前处于禁用状态
- 需要技能书才能学习
- 属于被动技能，不需要主动释放
