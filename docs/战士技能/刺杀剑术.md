# 刺杀剑术

## 技能基本信息
- **技能ID**: 3
- **技能名称**: 刺杀剑术
- **职业**: 战士 (vocation: 1)
- **技能类型**: 主动技能 (skillType: 1)
- **技能分类**: 基础技能 (skillClass: 1)
- **学习等级**: 7级自动学习
- **状态**: 正常使用

## 技能配置详情
```lua
[3] = {
    id = 3,
    name = "刺杀剑术",
    vocation = 1,
    skillType = 1,           -- 主动技能
    skillClass = 1,          -- 基础技能类
    commonCd = 0,            -- 无公共冷却
    isSwitch = true,         -- 切换技能
    specialBuffCond = 3,     -- 特殊BUFF条件3
    needCalPassiveProperty = true,  -- 需要计算被动属性
    priority = 1,            -- 优先级1（最高）
    isAutoLearn = true,      -- 自动学习
    autoLearnSkillLvl = 7,   -- 7级自动学习
    direction = 1,           -- 需要方向
    action = 1,              -- 动作类型
}
```

## 技能说明
刺杀剑术是战士最早学习的主动攻击技能，7级时自动获得。这是一个切换技能，可以在普通攻击和刺杀攻击之间切换。

## 技能特点
- **切换技能**: 可以开启/关闭刺杀模式
- **高优先级**: 优先级1，在技能组合中优先使用
- **特殊BUFF**: 需要满足特殊BUFF条件3
- **方向攻击**: 需要指定攻击方向

## 使用技巧
- 刺杀剑术适合对单个目标造成高伤害
- 在PK和打BOSS时效果显著
- 可以与其他技能组合使用

## 学习建议
- 7级时自动学习，是战士第一个主动技能
- 建议熟练掌握切换时机
