# 野蛮冲撞

## 技能基本信息
- **技能ID**: 5
- **技能名称**: 野蛮冲撞
- **职业**: 战士 (vocation: 1)
- **技能类型**: 主动技能 (skillType: 1)
- **技能分类**: 基础技能 (skillClass: 1)
- **学习等级**: 30级自动学习
- **状态**: 正常使用

## 技能配置详情
```lua
[5] = {
    id = 5,
    name = "野蛮冲撞",
    vocation = 1,
    skillType = 1,           -- 主动技能
    skillClass = 1,          -- 基础技能类
    commonCd = 1000,         -- 公共冷却时间1000ms
    isSwitch = false,        -- 非切换技能
    specialBuffCond = 0,     -- 无特殊BUFF条件
    needCalPassiveProperty = true,  -- 需要计算被动属性
    priority = 0,            -- 优先级0
    isAutoLearn = true,      -- 自动学习
    autoLearnSkillLvl = 30,  -- 30级自动学习
    direction = 1,           -- 需要方向
    action = 1,              -- 动作类型
}
```

## 技能说明
野蛮冲撞是战士的位移控制技能，30级时自动学习。该技能可以让战士快速冲向目标并造成伤害，同时具有击退效果。

## 技能特点
- **位移技能**: 可以快速接近敌人
- **控制效果**: 具有击退或眩晕效果
- **较长冷却**: 1000ms冷却时间
- **方向攻击**: 需要指定冲击方向

## 使用场景
- **PK战斗**: 快速接近远程职业
- **追击敌人**: 防止敌人逃跑
- **打断施法**: 打断法师和道士的施法
- **战术位移**: 调整战斗位置

## 使用技巧
- 在PK中用于快速接近法师和道士
- 可以用来打断敌人的技能释放
- 注意冷却时间，合理使用
- 可以配合其他技能形成连击

## 学习建议
- 30级时自动学习
- 建议在PK中熟练使用
- 注意技能释放的时机和方向
