# 烈火剑法

## 技能基本信息
- **技能ID**: 6
- **技能名称**: 烈火剑法
- **职业**: 战士 (vocation: 1)
- **技能类型**: 主动技能 (skillType: 1)
- **技能分类**: 基础技能 (skillClass: 1)
- **学习等级**: 35级自动学习
- **状态**: 正常使用

## 技能配置详情
```lua
[6] = {
    id = 6,
    name = "烈火剑法",
    vocation = 1,
    skillType = 1,           -- 主动技能
    skillClass = 1,          -- 基础技能类
    commonCd = 0,            -- 无公共冷却
    isSwitch = true,         -- 切换技能
    specialBuffCond = 3,     -- 特殊BUFF条件3
    needCalPassiveProperty = true,  -- 需要计算被动属性
    priority = 4,            -- 优先级4
    isAutoLearn = true,      -- 自动学习
    autoLearnSkillLvl = 35,  -- 35级自动学习
    direction = 0,           -- 无方向要求
    action = 1,              -- 动作类型
}
```

## 技能说明
烈火剑法是战士的高级攻击技能，35级时自动学习。这是一个切换技能，可以大幅提升攻击力，是战士后期的主要输出技能。

## 技能特点
- **高伤害**: 提供大量攻击力加成
- **切换技能**: 可以开启/关闭烈火模式
- **高优先级**: 优先级4，在技能组合中重要
- **特殊BUFF**: 需要满足特殊BUFF条件3

## 使用场景
- **PK战斗**: 对敌人造成巨大伤害
- **打BOSS**: 快速击杀BOSS
- **高等级战斗**: 后期主要输出技能

## 使用技巧
- 在PK中配合其他技能使用效果最佳
- 可以与其他切换技能组合
- 注意蓝量消耗
- 掌握技能释放时机

## 学习建议
- 35级时自动学习
- 建议作为主要输出技能使用
- 需要熟练掌握切换时机
