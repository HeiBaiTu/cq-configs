# 半月弯刀

## 技能基本信息
- **技能ID**: 4
- **技能名称**: 半月弯刀
- **职业**: 战士 (vocation: 1)
- **技能类型**: 主动技能 (skillType: 1)
- **技能分类**: 基础技能 (skillClass: 1)
- **学习等级**: 23级自动学习
- **状态**: 正常使用

## 技能配置详情
```lua
[4] = {
    id = 4,
    name = "半月弯刀",
    vocation = 1,
    skillType = 1,           -- 主动技能
    skillClass = 1,          -- 基础技能类
    commonCd = 0,            -- 无公共冷却
    isSwitch = true,         -- 切换技能
    specialBuffCond = 3,     -- 特殊BUFF条件3
    needCalPassiveProperty = true,  -- 需要计算被动属性
    priority = 2,            -- 优先级2
    isAutoLearn = true,      -- 自动学习
    autoLearnSkillLvl = 23,  -- 23级自动学习
    direction = 1,           -- 需要方向
    action = 1,              -- 动作类型
}
```

## 技能说明
半月弯刀是战士的群体攻击技能，23级时自动学习。这是一个切换技能，可以同时攻击前方多个敌人，是战士刷怪和群战的重要技能。

## 技能特点
- **群体攻击**: 可以同时攻击多个目标
- **切换技能**: 可以开启/关闭半月模式
- **中等优先级**: 优先级2
- **特殊BUFF**: 需要满足特殊BUFF条件3

## 使用场景
- **刷怪升级**: 同时攻击多个怪物，提高升级效率
- **群战PK**: 在多人战斗中发挥重要作用
- **副本清怪**: 快速清理小怪

## 使用技巧
- 在怪物密集的地方使用效果最佳
- 可以与其他技能配合使用
- 注意蓝量消耗

## 学习建议
- 23级时自动学习
- 建议在群怪时优先使用
