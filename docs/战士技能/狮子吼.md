# 狮子吼

## 技能基本信息
- **技能ID**: 7
- **技能名称**: 狮子吼
- **职业**: 战士 (vocation: 1)
- **技能类型**: 主动技能 (skillType: 1)
- **技能分类**: 基础技能 (skillClass: 1)
- **学习等级**: 43级（需要技能书）
- **状态**: 已删除/禁用 (isDelete: true)

## 技能配置详情
```lua
[7] = {
    id = 7,
    name = "狮子吼",
    vocation = 1,
    skillType = 1,           -- 主动技能

    isDelete = true,         -- 已删除/禁用
}
```

## 技能说明
狮子吼是战士的高级控制技能，原本在43级时可以通过技能书学习。该技能具有群体眩晕或恐惧效果，是战士在群战中的重要控制技能。

## 技能特点
- **群体控制**: 可以影响周围多个敌人
- **眩晕效果**: 使敌人无法行动
- **较长冷却**: 1000ms冷却时间
- **范围技能**: 不需要指定目标

## 使用场景
- **群战PK**: 控制多个敌人
- **副本战斗**: 控制怪物群
- **团队配合**: 为队友创造输出机会

## 注意事项
- 该技能当前处于禁用状态
- 需要技能书才能学习
- 43级时才能学习

## 学习建议
- 需要获得相应的技能书
- 建议在群战中优先使用
- 注意技能释放的时机和位置
