# 怪物攻城活动设计文档

## 活动概述

**活动名称**: 怪物攻城  
**活动类型**: 副本活动 (ActivityType = 7)  
**活动时间**: 每周日20:00-21:00  
**活动地点**: 盟重城副本  
**参与条件**: 提交1000YB入场费  
**活动目标**: 在1小时内消灭所有5波BOSS怪物  

## 活动配置设计

### 1. 活动总表配置

#### 1.1 修改 `data/config/activity/Activities.config`

```lua
[200] = {

    ActivityType = 7,  -- 副本活动

    TimeType = 2,  -- 每周固定时间

    Popup = true,  -- 弹窗提示
```

## 活动流程设计

### 1. 活动开始前
- 玩家可以在活动界面看到"怪物攻城"活动
- 显示活动时间：每周日20:00-21:00
- 显示参与条件：30级，1000YB入场费

### 2. 活动开始
- 每周日20:00活动自动开始
- 玩家可以进入盟重城副本
- 扣除1000YB入场费
- 显示活动开始提示

### 3. 怪物波次
- **第1波** (20:00)：10个沃玛教主
- **第2波** (20:10)：10个祖玛教主
- **第3波** (20:20)：10个赤月恶魔
- **第4波** (20:30)：5个妖兽烈焰狮王
- **第5波** (20:40)：3个神兽祝融

### 4. 活动结束
- **成功条件**：在21:00前消灭所有怪物
- **成功奖励**：退回1000YB + 额外奖励
- **失败条件**：21:00时仍有怪物存活
- **失败结果**：无奖励，无惩罚

## 技术实现要点

### 1. 怪物刷新机制
- 使用定时器控制怪物刷新时间
- 每波怪物刷新前发送提示信息
- 怪物死亡后检查是否还有剩余怪物

### 2. 活动状态管理
- 记录活动开始时间
- 跟踪每波怪物的刷新状态
- 监控怪物死亡情况

### 3. 奖励发放机制
- 活动结束时检查所有怪物是否被消灭
- 根据结果发放相应奖励
- 退回入场费给所有参与者

### 4. 玩家管理
- 限制最大参与人数（50人）
- 防止重复进入
- 活动期间不允许PK

## 注意事项

### 1. 配置验证
- 确保所有怪物ID、地图ID、物品ID都是有效的
- 验证时间配置是否正确
- 检查奖励配置是否合理

### 2. 平衡性考虑
- 怪物数量和强度需要根据服务器情况调整
- 入场费金额需要平衡游戏经济
- 奖励设置要合理，不能过于丰厚

### 3. 测试建议
- 在测试环境先验证活动流程
- 测试怪物刷新和死亡检测
- 验证奖励发放机制
- 检查时间控制是否准确

### 4. 后续优化
- 可以根据玩家反馈调整怪物数量
- 可以添加更多奖励类型
- 可以增加活动难度等级
